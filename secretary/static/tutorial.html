把知识库接到其他 AI（MCP）

Codex CLI、Claude Code 和 Gemini CLI 都能按需查找并读取已归档资料。接口默认关闭，开启后仅供本机只读访问。

  1. 在项目目录安装 requirements-mcp.txt 中的依赖。
  2. 退出旧实例，加上 --memory-mcp 启动源码版，使用当前资料目录并保持程序运行。
  3. 在你的客户端添加 stellar-memory，再请它搜索一份已归档的资料。

客户端可能将读取的资料作为上下文发送给它使用的模型。
