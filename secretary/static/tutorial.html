把知识库接到其他 AI（MCP）

Codex CLI、Claude Code 和 Gemini CLI 都能按需查找并读取已归档资料。接口默认关闭，开启后仅供本机只读访问。

  1. 在「模型与设置 → 连接 AI 助手」开启只读访问。
  2. 选择客户端，复制配置并合并到提示的配置文件。
  3. 测试连接，重新打开客户端，让它搜索资料并引用附件或 PDF 页码。

客户端可能将读取的资料作为上下文发送给它使用的模型。
