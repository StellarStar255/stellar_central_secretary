在常用浏览器中采集

如果 Google 拒绝专用浏览器登录，可以在你平时使用、已经登录 ChatGPT 的 Chrome、Comet 或 Edge 中采集。无需在自动化窗口中登录。

  1. 在常用浏览器打开扩展管理页面，开启开发者模式。

  3. 打开目标 ChatGPT 会话，点击「Stellar 知识采集」扩展，再点击「一键归档当前页面」。

自定义模型 API

支持 OpenAI 兼容的 Chat Completions 接口，可使用第三方或本地模型服务。

已保存密钥时留空保持；更换 API 地址需要重新填写。密钥只保存在本机，不包含在知识库备份中。

仅在模型支持图片时勾选。未启用时只整理文字，图片原件仍保存。

按服务文档选择参数；多数兼容服务使用 max_tokens。

测试只发送一条简短消息，不发送知识库资料；服务可能计费。

部分读取会标注范围；已有完整正文会保留，最近片段另存。

登录有效时自动读取；需要重新登录时会显示任务标签页并等待确认。已有标签页与登录资料会保留。

读取结束后，空闲且没有其他页面的专用浏览器会自动退出。登录资料保留，下次读取时复用。

关闭知识秘书的专用浏览器及其中页面，保留登录资料；不关闭你的日常浏览器。

登录并自动读取 ChatGPT

发送 ChatGPT 会话链接后，会按上方选项打开专用 Chrome 的任务页面；登录有效时自动读取。需要登录时请在任务页面手动登录，再点击「我已登录，开始读取」。读取完自动归档并总结，按设置关闭任务新开的页面。专用实例的连接端点仅监听本机。如果 Google 仍拒绝登录，请使用常用浏览器中的采集扩展。登录状态保存在本机专用浏览器目录，备份不包含登录信息。网页登录和读取阶段可能仍受网站限制，不保证任意账号或会话都能读取。

浏览器扩展（备选方式）

在 Chrome 扩展管理中开启开发者模式，加载本项目的 browser-extension 文件夹。打开已登录的对话后点击扩展，即可直接归档。服务未启动时会下载采集文件，下次拖入即可。

扩展只采集当前已显示内容。长对话请先滚动加载完整内容；扫描 PDF、图片、音视频目前仅保存原件。
