网络连接与代理

不知道怎么填？看三个步骤
  1. 打开你平时用来访问 ChatGPT 的代理软件，保持它运行。
  2. 在代理软件的设置里找「端口」「入站」或「本地代理」，记下类型和旁边的数字。
  3. 模型连接填 HTTP / Mixed 的数字；浏览器也能选 SOCKS5。下面只需要选类型、填数字，不用自己拼地址。

例如「HTTP 7897 / SOCKS 1080」：模型填 7897；浏览器选 SOCKS5、填 1080。示例数字不是固定值，以你软件显示的数字为准。

选择示例后会自动填好，只需核对端口数字。

只填数字。例如代理软件显示「Mixed 7897」，这里就填 7897。不要填写网页网址。

用于 Claude、Codex、Gemini 和自定义模型 API。指定代理连接失败时会提示错误；本机模型 API 始终直连。

例：代理软件显示「SOCKS 1080」，上面选 SOCKS5、端口填 1080。显示「HTTP 7897」或「Mixed 7897」，选 HTTP 或 Mixed、填 7897。这里不支持需要账号密码的 SOCKS5。

作用于本程序打开的专用 Chrome。常用浏览器与采集扩展使用它们自己的代理设置。修改后请保存设置；若专用浏览器已打开，先点击下方「关闭专用浏览器」再读取，登录资料会保留。

登录并自动读取 ChatGPT

发送 ChatGPT 会话链接后，会按上方选项打开专用 Chrome 的任务页面；登录有效时自动读取。需要登录时请在任务页面手动登录，再点击「我已登录，开始读取」。读取完自动归档并总结，按设置关闭任务新开的页面。专用实例的连接端点仅监听本机。如果 Google 仍拒绝登录，请使用常用浏览器中的采集扩展。登录状态保存在本机专用浏览器目录，备份不包含登录信息。网页登录和读取阶段可能仍受网站限制，不保证任意账号或会话都能读取。

浏览器扩展（备选方式）

在 Chrome 扩展管理中开启开发者模式，加载本项目的 browser-extension 文件夹。打开已登录的对话后点击扩展，即可直接归档。服务未启动时会下载采集文件，下次拖入即可。

扩展只采集当前已显示内容。长对话请先滚动加载完整内容；扫描 PDF、图片、音视频目前仅保存原件。

公司模式

默认关闭。关闭时按当前模型和自动总结设置处理，不弹出额外确认；开启后，公司资料首次使用模型服务时需要确认。

公司资料的模型服务

确认公司允许的服务和当前账户后，后续公司资料可按自动总结设置处理。在本应用中更换模型后端或 API 配置后需要重新确认。CLI 外部账户或服务配置变更后，请主动撤销并重新确认。此确认不代表公司已正式授权。

撤销会阻止后续公司资料调用；已发出的模型请求无法撤回，正在处理的任务可在任务列表中停止。
