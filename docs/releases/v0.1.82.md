# Stellar Secretary v0.1.82

Play a Live Photo’s MOV companion from its photo preview.

- Import a photo and its same-name MOV together, or append the MOV to the same item later. HEIC/HEIF and JPEG photos gain a **Play Live Photo** control when an unambiguous companion is available. Pairing prefers the same attachment batch; ambiguous matches are not guessed.
- Open playback from the photo viewer, pause or seek, then close the player to return to the photo. Closing stops playback and preserves the underlying dialogs. Both original files remain downloadable, and video byte-range streaming stays available.
- Look up companions when opening a photo from details, compact previews or chat. Without a companion, HEIC previews explain that only the still photo is available and how to append its MOV. Motion cannot be reconstructed from a single still HEIC.
- Include English and Chinese controls and guidance, plus updated README instructions.

Validation: 309 Python tests (10 platform-dependent skips), chat UI regression, real-browser MOV decoding/playback/pause/resume, late companion append, exact original downloads and byte ranges, bilingual labels, native Mac WKWebView playback and return-to-photo behavior, and frozen Mac smoke checks. Tests use synthetic materials and make no model calls.

中文：本版支持从照片预览播放实况照片配套的同名 MOV。可同时导入 HEIC 与 MOV，也可后续将 MOV 追加到同一份资料。找到明确配对后，照片查看器显示“播放实况”，支持播放、暂停、拖动进度，关闭播放器返回照片并停止播放，两份原件完整保留。详情、紧凑预览和对话中的照片均可使用。缺少配套视频时会显示提示，单张静态 HEIC 无法补出动态内容；同名候选不明确时不会自动配对。
