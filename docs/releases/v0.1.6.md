# Stellar Secretary v0.1.6

首次公开发布，使用 MIT 许可证。提供本机运行的对话式知识管理器，保存链接、文件和笔记，使用本机已登录的 Codex / Claude CLI 生成摘要及带来源的问答。

## 功能

- 对话式投放链接、文件与笔记，自动生成摘要、分类和标签。
- SQLite 全文检索、中英文关键词查找、原链接与原文件取回。
- 在专用 Chrome 中手动登录 ChatGPT，通过原浏览器窗口读取对话；支持逐屏补读、失败保留旧正文和替换前备份。
- 归档会话以提问和回答分栏展示，支持收起、标题、加粗、列表及代码块。
- 提供浏览器采集扩展、ZIP 数据备份，以及单独重试摘要的脚本。
- 统一 Stellar Secretary 品牌与暖橙色图标。

## 隐私与要求

- 发布内容仅包含源码、测试、文档及启动脚本，不包含私人对话、截图、数据库、浏览器登录资料或 CLI 凭据。
- macOS 启动脚本要求 Python 3.10+；读取私有 ChatGPT 会话需要 Google Chrome；摘要和提问需要安装并登录 Codex CLI 或 Claude Code。
- AI 处理会把相关资料文本发送到所选模型服务。默认服务仅监听本机，不适合直接公开到互联网。
- 网页结构、登录限制和页面可加载的历史会影响采集范围；可在详情核对正文，并使用导出文件补充。
- 当前使用关键词驱动的 RAG 和少量上下文简称规则，尚未提供通用语义向量检索。

## 开始使用

下载 GitHub 自动提供的 Source code 压缩包，解压后运行 `./start.sh`；macOS 也可双击「启动知识秘书.command」。默认地址为 `http://127.0.0.1:8768`。
