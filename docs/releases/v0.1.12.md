# Stellar Secretary v0.1.12

新增知识库备份导入，以及后台读取和任务网页自动清理选项。

- 左侧栏和知识库窗口新增「导入知识库备份」，选择本程序导出的 ZIP 即可合并恢复正文、摘要、标签、分类与原文件。
- 重复资料自动跳过，已有内容保留；导入后重新建立检索索引，并显示新增和跳过数量。异常导入回滚，不留下部分资料。
- 「模型与设置」新增后台打开浏览器、读取后自动关闭本次新开网页两项设置，默认开启。
- 登录有效时自动读取；需要登录时显示任务标签页等待用户确认。成功、失败和取消后按设置清理任务页面，保留原有标签页与登录状态。

验证包括备份合并、原文件恢复、重复跳过、全文检索、错误回滚与设置持久化；使用独立真实 Chrome 验证读取成功、失败、取消、保留网页及启动占位页归属。

安装版可从「模型与设置 → 版本与升级」更新。macOS 安装包使用 Developer ID Application: Qiliang Huang (3QCL9WNFBB) 签名，通过苹果公证和票据装订。Windows 安装包未做代码签名，附件提供 SHA256SUMS.txt。
