# Stellar Secretary v0.1.140

- Settings shows the active library folder. **Change folder** opens the system folder picker and checks the selected destination before you schedule a move.
- Once a move is scheduled, **Restart now** restarts the app when tasks are idle. On startup, the app shows the new library folder or explains why it is still using the original folder.
- Backup usage, the latest successful backup, and verification status reflect the configured backup folder. Open either the active library folder or the saved backup folder directly from Settings.

## 中文

- 设置页直接显示当前记忆目录。点击「更改目录」可用系统选择器选新目录，检查通过后再保存迁移计划。
- 保存迁移计划后可点击「立即重启」。程序空闲时才会重启，启动后会显示迁移到的新目录，或说明迁移失败的原因和仍在使用的原目录。
- 备份占用、最近成功的备份和验证状态按当前备份目录显示。设置页可以直接打开当前记忆目录和已保存的备份目录。
