# Stellar Secretary v0.1.76

Fix attachment downloads from the built-in macOS viewer.

- Downloading original, grouped and added attachments now opens the native save dialog. Video downloads keep the player and material details open.
- The save dialog uses the original filename, including Unicode names. Preparation, progress, completion and cancellation are shown in the application.
- Downloads stream to a temporary file and replace the destination only after completion. Failed transfers preserve existing files and remove incomplete temporary files.
- Correct the original-video download fallback URL, and support native downloads of batch archives, backups and the browser extension.

Validation: actual macOS WKWebView playback and download tests cover original, grouped and added videos, Unicode filenames, cancellation and visible feedback. The Python suite passed 300 tests (10 skipped); chat UI regression passed.

中文：修复 Mac 内置播放器中点击“下载附件”没有反应的问题。原始、组合和追加附件均可弹出保存窗口，保留原文件名并显示下载结果，播放器保持打开。下载采用分段写入和完成后替换，取消或失败时保留已有文件。已通过实际 Mac WebKit 场景和完整回归验证。
