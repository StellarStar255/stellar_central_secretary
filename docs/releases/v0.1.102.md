# Stellar Secretary v0.1.102

Archive arrangements with concrete dates, reuse matching records quickly, and recover duplicates from the recycle bin.

- Show full local archive timestamps in the library preview, with a separate last-update timestamp.
- Resolve relative dates in short personal arrangements against the original message date. Keep the original text and the fixed interpretation for search; recurring arrangements retain their recurrence wording.
- A standalone **建档** saves the preceding user material in the current conversation. Empty context prompts for content instead of archiving the command itself.
- Confirm matching archived arrangements directly from current records without a model call. Old timetable conditions do not turn an exact record confirmation into an unrelated conflict analysis. Explicit rechecks retain the normal model path.
- Treat an optional leading **我** before an arrangement date as the same speaker, while keeping different people, times and objects separate. Matching live arrangements are reused without creating another record or rerunning AI.
- When only a deleted duplicate exists, show an explicit restore action and retain the input. Restoration preserves the original ID, archive date and content; changed recycle-bin versions are checked before restoring.
- Display the date interpretation once, including in older summaries. Keep distinct details and original stored content.
- Replace raw connection errors with a local-service explanation and retain unsaved input.

Existing duplicate records are not automatically deleted or merged.

Validation includes full Python and JavaScript regressions and isolated real-browser checks for local timestamps, contextual archiving, direct record confirmation with old timetable history, optional-speaker reuse, summary display and recycle-bin recovery. Tests use synthetic records.
