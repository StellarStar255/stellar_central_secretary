# Stellar Secretary v0.1.47

Make short archives lighter, reduce long-document blocking, and show where time is spent.

- Short text summaries now target 1–3 sentences, up to 120 Chinese characters; medium text targets 100–200 characters. Long material keeps its existing segmented coverage. Brief text-only grouped/supplemental material uses the same adaptive prompt.
- Short plain-text tasks and interactive questions use a separate model lane from long documents. Each lane runs one task, with at most two model calls overall. Active jobs are not interrupted.
- Archive cards, library rows and details show queue/preparation, model and total elapsed time, plus the current stage. The model phase includes CLI/worker startup, connection and generation; stage timing is diagnostic, not a token progress estimate. The latest 100 completed jobs are retained in memory for this app session, without source text or credentials.
- Visible windows refresh roughly once per second during active work, with fewer idle requests and throttled chat-history sync. Transient timing values do not get written into conversation history.
- **Archive only, skip summary** saves searchable text, attachments and links without AI or automatic browser capture. Links remain unread, saved items stay unsummarized after restart, and **Reorganize** can generate a summary later.
- Existing originals, notes, images, tags, API settings and summaries are preserved. CLI startup and provider latency still vary; no fixed completion time is promised.

中文：短资料不再一律生成长摘要；短任务和问答与长文分开调度，整体最多两路模型调用。新增阶段与耗时显示、活动时快速刷新，以及「仅归档，暂不总结」选项。计时仅存在于本次运行内存中，不包含正文或密钥。

Validated with deterministic blocked-long-job tests, adaptive-prompt and restart-safe archive-only tests, and a real bilingual browser UI using synthetic delayed models. No real model account or user material was used for performance tests.
