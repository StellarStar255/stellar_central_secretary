# Stellar Secretary v0.1.92

Faster library conversations with live, visible progress while an answer is being prepared.

- **Live request progress:** see the actual server stage, elapsed waiting time and relevant-item count while the app prepares context, waits for the model lane, plans a search, retrieves material, prepares original images or generates an answer. Slow model calls display a waiting notice. Progress ends on success or failure; it contains no document text or titles.
- **Instant greetings:** whole-message greetings and thanks are answered locally without a model call or search. A greeting followed by a request still retrieves material normally. Social turns do not crowd out earlier source-backed conversation context; explicit archive controls retain priority.
- **Fewer model calls:** pure chat or creative replies can finish in the first model call. Explicit short clarifications referring to recently cited short documents refresh that evidence and answer without a separate planning call. New topics, missing sources and long documents retain full retrieval.
- **Responsive question scheduling:** library questions use a dedicated interactive lane so background short summaries do not occupy their queue. Simple questions use a lower reasoning budget where supported; detailed analysis retains a higher budget. Original-image checks, source citations and company-data confirmation remain in place.
- **Visible timings:** expand Processing time beneath an answer to see queue, planning, local search, image preparation and model-answer durations. Local replies identify that no model or search was used. Online model response time still depends on the service and network; this release does not promise instant model answers.

Validation: 346 unit tests passed with 10 platform-specific/opt-in skips; chat UI, live HTTP/browser progress and elapsed-time checks, success/error cleanup, schedule follow-ups, company-data confirmation and Chinese/English checks passed. Synthetic data was used for browser regressions. No private screenshots, knowledge records or test conversations are included.

中文：本版增加问答实时进度，展示后端实际执行的步骤、等待秒数和相关资料数量；模型返回较慢时明确提示正在等待，完成或失败后自动结束显示。回答下方可展开查看各阶段耗时。

完整问候与致谢在本地即时回复，不调用模型、不搜索知识库，也不挤掉此前引用资料的对话上下文。普通闲聊可以一次模型调用完成；明确沿用近期短资料的简短补充会重新读取资料后直接回答，省去检索规划请求。新话题、长资料和失效来源仍走完整检索。

知识库问答使用独立交互队列，减少后台摘要造成的等待；保留原图核对、来源引用、公司资料确认及显式归档操作。在线模型调用仍受服务和网络耗时影响。

The Windows large-PDF browser check now waits for conversation initialization before changing Archive only, avoiding a startup race in the test.
