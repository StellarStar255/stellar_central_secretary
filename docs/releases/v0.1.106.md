# Stellar Secretary v0.1.106

Name conversations and keep the sidebar tidy.

- Rename chats using the small pencil beside each title, or double-click the title. Custom names persist across reloads and background question updates; concurrent edits show a conflict instead of silently overwriting another name.
- Show short provider names for URL-only conversations, and use the archived material title when available. Manually chosen names take priority.
- Hover over a recently archived item to reveal a small dismiss control. Dismissing hides only the sidebar entry and remembers the preference in this browser; the original material remains in the library.
- Keep rename and dismiss actions accessible by keyboard, with Chinese and English labels.

Validation: full Python unit tests, JavaScript chat regressions, and isolated browser checks for renaming, persistence, conflict handling, title escaping, hover controls and archive preservation.

中文：支持通过侧栏小铅笔或双击标题重命名对话，名称会持久保存，后台问答和刷新不会覆盖；网址对话显示简短名称或归档标题。“最近归档”悬浮时显示小叉，可仅隐藏侧栏条目，知识库资料保留，隐藏状态在当前浏览器中保存。
