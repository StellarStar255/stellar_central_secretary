# Stellar Secretary v0.1.18

修复 AES 加密 PDF 因安装包缺少读取组件而无法提取正文、无法总结的问题。

- 安装包补齐 pypdf 的加密依赖和特殊字体解析支持，支持无需打开密码的 AES 文档。
- 区分需要密码、读取组件缺失、文件损坏和扫描件，界面展示具体解析原因，避免笼统显示“格式不支持”。
- 资料详情新增「重新解析原文件」，可直接重试本机已保存的原件，无需重新上传；解析失败保留原件和已有正文。
- 修复空白 PDF 仅有程序生成的页码却被误认为提取成功的问题。
- 超过 24 万字符的 PDF 完整保留可检索正文，摘要改为有界的长文概览，并明确标注使用全文分布的10处采样片段，避免因长度限制直接失败。

验证包括 AES 提取、需要密码、依赖缺失、空白扫描件识别、重新解析时原件完整性与正文保护，以及实际安装包中的 AES 文件归档和重解析。

macOS 安装包使用 Apple Developer ID 签名，完成苹果公证及票据装订。附件提供两平台安装包及 SHA256SUMS.txt。
