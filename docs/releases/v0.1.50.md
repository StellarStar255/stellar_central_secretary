# Stellar Secretary v0.1.50

Fix Windows settings scrolling and local CLI detection.

This release distributes the Windows x64 installer. The macOS build passed its checks, but its DMG is withheld because CI has no Apple Developer ID signing/notarization credentials. macOS users should keep their existing version.

- Settings now scroll within an isolated, clipped surface while the dialog frame stays fixed. Modal backdrops use dimming without background blur to avoid Chromium repaint artifacts, blank areas and underlying content appearing over the dialog.
- Windows CLI discovery now checks the per-user OpenAI Codex installation, npm global shims, local binaries and Scoop shims when the desktop process has an outdated PATH. Commands already found on PATH keep priority.

Validated on a real Windows Qt/Chromium desktop window with default graphics rendering, dark mode and 20px interface text: repeated wheel scrolling, rapid scrollbar drags in both directions, and dialog closing. The earlier blur-only change still showed a blank region during rapid dragging; the isolated scrolling surface passed the repeated checks. Codex was detected at the installed per-user path. Python regression suite: 148 tests, 3 skipped.
