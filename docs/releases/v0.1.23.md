# Stellar Secretary v0.1.23

macOS 新增独立桌面窗口，与网页模式自由切换。

- 右上角和托盘菜单都提供模式切换，记住上次选择。
- 桌面窗口使用系统 WebKit，支持缩放、最小化、文件选择与拖入；原链接和 PDF 新标签页交给常用浏览器。
- 关闭窗口后继续在托盘处理任务，点击 Dock 或托盘可重新打开；退出仍通过应用菜单。
- 两种模式共用知识库、设置和本机对话记录。旧浏览器对话在刷新后迁移；修改后按对话合并，避免空窗口覆盖已有记录。
- 桌面模式下载使用系统保存对话框，支持标准复制、粘贴和全选菜单。

独立窗口适用于 macOS 安装版；Windows 继续提供网页界面。
macOS 安装包使用 Apple Developer ID 签名，并完成苹果公证和票据装订。
