# Stellar Secretary v0.1.84

Double-click library preview content to open the full item details for editing.

- Double-click the right-hand preview’s body, source information or blank content area to enter the same details view as **Full details / edit**.
- Keep title double-click for inline renaming and preserve attachment, link, button and input interactions. Opening details follows the existing save-before-navigation path so title drafts are saved first. Empty or loading previews do not open an item.

- Retry briefly when Windows temporarily locks an update status file. Each write uses a separate temporary file; retries are bounded, persistent errors remain visible and the previous status stays intact on failure.

Validation: real-browser library regression covers source and summary double-click, the correct item opening above the library, title editing and draft saving before navigation. Chat UI regression passed.

Windows validation also covers transient reader-lock recovery, bounded persistent-lock failure and immediate propagation of unrelated write errors.
