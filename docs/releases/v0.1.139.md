# Stellar Secretary v0.1.139

- Browse for separate library and backup folders using the system folder picker. Before scheduling a library move, see the estimated data size, available space, and whether the destination is empty and writable.
- After saving the backup location, choose **Back up and verify now** to create and check a snapshot. The app shows the folder where it wrote the verified backup.
- **Test ChatGPT connection** checks the public homepage in an isolated Chrome session using your capture proxy settings. The result identifies proxy, TLS, and HTTP errors separately from the model connection test.

## 中文

- 可用系统文件夹选择器分别设置记忆保存目录和备份目录。保存迁移设置前，可以查看预计迁移大小、磁盘可用空间，以及目标目录是否为空、是否可写。
- 保存备份目录后，点击「立即备份并验证」即可创建并核验备份，完成后会显示实际写入的目录。
- 「测试 ChatGPT 连接」按当前采集代理设置，用临时 Chrome 配置访问公开首页。结果分别提示代理、TLS 及 HTTP 错误，模型连接仍可独立测试。
