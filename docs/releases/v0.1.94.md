# Stellar Secretary v0.1.94

More complete library conversations, useful references and visible background completion.

- **Complete keyword catalogs:** listing records on a topic returns distinct matches and a real count, with 20 records per page. It searches the displayed keywords across indexed content and metadata and excludes the recycle bin. Counts describe keyword matches, not a guarantee of all semantically related material; pagination reflects the current library.
- **Conversation conditions:** explicit ownership confirmations, corrections and instructions to use a source are retained separately from recent turns within the same chat. Review or clear them above the composer. They remain user-stated conditions, not verified source facts.
- **Streaming answers:** compatible APIs can show provisional text before completion when enabled in API settings. Only complete answers with valid source numbers are saved. CLI backends that return text at completion retain live stage progress.
- **Useful citations:** source cards show excerpts and attempt to locate the cited text in the original. PDF page navigation is preserved. Double-click linked references to open the original URL, including older references outside recent records; single-click still opens archived material.
- **Completion notifications:** opt-in completion/failure notifications are connected to desktop hosts and browser mode. They omit source titles and contents and open Tasks for details and retry. Delivery depends on system/browser permission; browser background throttling can delay browser notifications.
- **Recent-answer reuse:** a bounded, in-memory cache reuses unchanged source-backed answers, with a maximum five-minute lifetime. Context, time, records, original/added-file metadata, model and semantic-index changes invalidate reuse; company-data authorization is still checked. **Check again** forces fresh retrieval and generation. Failure preserves the previous answer and references.
- **State refresh:** returning to a hidden window or tab immediately refreshes archive status, avoiding stale “organizing” labels after background work has completed.

Validation includes the full unit suite, real-browser catalog pagination, API-worker streaming before completion, context beyond six turns and clearing across reloads, excerpt location, cache/manual refresh and failure preservation, completion notification routing, company-data authorization and Chinese/English UI. Release builds also test streaming inside the frozen application. All test material is synthetic; private library records and images are not included.
