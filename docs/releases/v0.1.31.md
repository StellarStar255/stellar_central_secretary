# Stellar Secretary v0.1.31

新增自定义标签与个人速记，并改进专用浏览器回收。

- 资料详情可添加标签、点击 × 删除；标签立即参与组合搜索和资料问答检索。
- 手动维护后的标签在重新解析、重新整理及备份恢复后保留，删除的标签不会被 AI 加回来。
- 在「资料摘要」上方新增「我的速记」，支持文字、粘贴/拖入/选择图片、缩略图查看和删除，自动保存在本机。
- 速记与原文、AI 摘要分开保存；不参与 AI 摘要和问答，重新解析及整理不会覆盖。速记文字可在知识库搜索，ZIP 备份包含速记及其图片。
- 保留草稿与并发保存检查，避免后台刷新或另一窗口更新时静默覆盖。
- 没有其他页面的空闲专用浏览器在任务完成后自动退出；设置中增加「关闭专用浏览器」，保留登录资料并避开日常浏览器。
- 速记图片拖放独立处理，不会误加到聊天附件，也不会留下遮挡页面的拖放提示。
- 新增功能支持简体中文与 English。

English: Edit searchable tags in item details. Add locally autosaved **My quick notes**, including pasted images, above Summary. Manual tags and notes survive AI regeneration and backup restore. Notes are excluded from AI requests. Dedicated browsers can be closed from settings, and empty idle instances exit automatically after capture.

macOS 安装包使用 Apple Developer ID 签名，完成苹果公证及票据装订。
