# Stellar Secretary v0.1.37

在「模型与设置」中增加界面字号调节。

- 字号范围 12–24 px，默认 14 px；拖动即时预览，松开自动保存，可一键恢复默认。
- 对话、资料详情、菜单和弹窗文字按比例调整，保留原有版式与图表尺寸。
- 偏好保存在本机，刷新或重启后恢复，桌面和网页模式共用。
- 连续调整按顺序保存，保存失败时恢复已保存的字号；支持中英文。
- 使用临时资料验证预览、刷新恢复、重置、失败回退、移动布局和草稿保留；原文、摘要和速记不因字号变化而改变。

English: Adjust interface font size in Models & settings, from 12 to 24 px. Preview instantly, save on release, or reset to the default 14 px. Desktop and browser modes share the locally stored preference.

macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
