# Stellar Secretary v0.1.43

Links sent together belong to one archive.

- Multiple links in a single message are grouped by default, alongside any annotation, images and files. **Group into one archive** is also available explicitly.
- Append several links to an existing archive as one batch with one supplemental summary.
- Save sources first, then read accessible public text in the background. Each source shows its read/unread state; unavailable links remain with their annotations and do not block the rest.
- Summaries and scoped answers distinguish readable content from unread references. Query-string question marks do not trigger model questions.
- Re-read grouped sources without discarding previously captured content, edited text or image descriptions. Backups retain source URLs, read statuses and captured text.
- Up to 20 links per group, with bounded text overviews. Sign-in-only, local and inaccessible pages remain explicit unread references; users can open them and append their content. Grouping does not automatically open multiple login windows.

中文：同次发送的多个链接默认合为一档，支持混合文字、图片和文件；追加资料也可一次提交多个链接。逐个保存来源与读取状态，失败不影响整组，摘要明确读取范围。

Validated using synthetic mixed-success sources, scoped questions, grouped appends, backup restoration, query-string handling, browser interaction and frozen-app checks. The macOS installer is signed with Apple Developer ID and notarized.
