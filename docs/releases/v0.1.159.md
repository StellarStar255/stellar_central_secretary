# Stellar Secretary v0.1.159

The Library preview and full item view now render Markdown in archived text. Tables show column headings and wrap long cells. Headings, emphasis, lists, quotations, links and code are also formatted for reading.

Use **Copy Markdown** beneath a table to copy its source. The text editor still opens the original Markdown. Existing archives gain the new reading view immediately.

## 中文

知识库预览和资料详情现在可以直接阅读 Markdown 正文。表格按行列显示，较长的单元格会换行。标题、粗体、斜体、列表、引用、链接和代码也会按格式展示。

点击表格下方的「复制 Markdown」可复制表格源码，编辑正文时仍可查看和修改原始标记。已有归档直接生效。
