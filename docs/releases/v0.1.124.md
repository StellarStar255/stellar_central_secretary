# Stellar Secretary v0.1.124

Fix Mac updates and archive refresh, and improve iPhone uploads and conversations.

- Fix a lock that could stall macOS in-app updates before downloading. The updater creates its library backup in the background and checks for active tasks before handing off to the installer.
- Keep existing chat messages mounted during archive refresh and keep closed item details from reopening when a background response arrives in the desktop app or browser.
- Give pasted quick-note images with generic filenames a readable name using on-device text recognition and, on macOS, image classification when needed. The original image bytes are preserved.

- The iPhone companion source shows uploads awaiting delivery and a recent archive list with saved, processing, completed, and failed states. For an attachment without extracted text, the receipt confirms that the original can be opened.
- Enlarge the iPhone chat composer and preserve Pinyin composition. The first message can open the desktop's current conversation or start one when the desktop has no conversations.
- Send a screenshot, photo, or file in chat, with an optional message. If you send only an attachment, the desktop saves the original and summarizes it in the conversation. Photos can be summarized without OCR text when the model supports image input.
- Add desktop nicknames and pairing times for paired devices. Phone automatic summaries are available with separate approval for the current model destination and automatic summarization enabled on the desktop.
- This release provides desktop installers and the matching iPhone companion source. The iPhone app is available through development testing.

- 修复 macOS 应用内升级可能在下载前卡住的问题。升级备份在后台运行，交接给安装程序前会再次检查是否有活动任务。
- 桌面窗口和网页在归档刷新时保留已有聊天消息，已关闭的资料详情也不会被迟到的后台刷新重新打开。
- 直接粘贴到「我的速记」且使用通用文件名的图片，自动用本机识别出的文字或 Mac 图像类别命名，保留原图。
- 手机归档页显示待发送和最近归档的状态。聊天输入框支持拼音组字，截图、照片或文件可以和文字一起发出，也可以单独发送并在当前会话中生成摘要。首次发送可接续电脑当前对话，电脑没有对话时会新建。桌面可修改已配对设备的备注并查看配对时间，手机归档支持单独授权自动摘要。本次发布提供桌面安装包和对应的 iPhone 源码。
