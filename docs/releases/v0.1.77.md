# Stellar Secretary v0.1.77

Append files directly from quick notes and arrange attachments in the order you want.

- Paste images, videos or documents into quick notes to append them directly to the current item’s All attachments section. Mixed clipboard text stays in quick notes; picking and dropping files use the same flow. Upload feedback and retry preserve the selected originals, and large files use chunked upload. This shortcut does not trigger AI summarization.
- Drag attachment cards across original and added batches to reorder them. A visible handle also supports arrow-key adjustments. Changes save automatically, appear consistently in details, compact previews and the image gallery, and survive restart and backup export/import. Newly appended files follow the saved order; deletion retains the relative order of remaining attachments.
- Sorting changes only presentation metadata. Originals, URLs, body text and summaries remain intact. Concurrent order edits are checked before saving, failed saves restore the displayed order, and cancelled drags make no changes. Active title and note drafts remain intact.
- Keep existing quick-note images viewable and removable, and synchronize note-save status after attachment updates.

Validation: real browser regressions cover cross-batch dragging, keyboard adjustments, cancellation, failed-save rollback, same-name attachment identities, preview/detail/gallery consistency, mixed clipboard files and text, direct pick/drop, retry and 9 MB chunked uploads. Backup tests cover batch-ID remapping and older backups without an order field. Python regression: 303 tests, 10 skipped; chat UI regression passed.
