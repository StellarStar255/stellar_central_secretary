# Stellar Secretary v0.1.71

Fix duplicate Windows tray hosts after updates and improve desktop rendering stability.

- Windows acquires a single-instance lock before checking the local service or constructing the desktop. Concurrent launches wait for the existing host, then reuse its window. The lock is released on exit and can be recovered after a crash.
- Desktop ownership is published before the service accepts requests. A host attaching to an existing service claims its lease before opening the shared browser profile; a rejected host exits instead of leaving another tray icon running.
- The update helper launches the application at most once, including when recording the successful restart fails. The tray icon is removed when the desktop event loop exits.
- Windows uses software rendering in both Chromium and Qt Quick to avoid graphics-driver artifacts. Linux and macOS retain their existing rendering configuration.
- Windows packaging excludes incompatible third-party copies of the system ICU libraries that can prevent Qt from loading on machines with Anaconda installed.
- Desktop regression checks race three cold launches, verify window reuse after closing and reopening, exercise native window resizing, and capture the native rendered window. Existing in-app video playback and automatic-update checks remain enabled.

Includes the video player, title autosave, Windows update handoff, Linux runtime dependencies and macOS startup fixes from v0.1.69.

中文：修复 Windows 升级后重复托盘图标及窗口无法正常打开的问题。启动前先获取单实例锁，连续启动会等待并唤起现有窗口；附加到本地服务的桌面宿主先确认归属，再打开共享浏览器缓存，被拒绝的宿主会退出。更新助手即使写入结果失败也不会再次启动程序，退出时及时移除托盘图标。Windows 的 Chromium 和 Qt Quick 均改用软件渲染，处理显卡驱动兼容性引起的花屏，并修复打包时误收集 Anaconda 同名 ICU 库导致 Qt 无法加载的问题。保留 v0.1.69 的视频播放、标题自动保存及三平台修复。

升级提示：安装新版前，首次需完全退出已运行的旧版托盘实例，再运行安装包覆盖升级；本地知识库仍保存在安装目录之外。新版本的重复启动会复用现有桌面窗口。
