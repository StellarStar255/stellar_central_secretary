# Stellar Secretary v0.1.73

Read selected PDF pages, follow source references, recover individual attachments, manage backups and resume large uploads.

- PDF attachments offer explicit ranges of 1–10 consecutive pages, next-five-page continuation and local OCR. Selected text stays separate from intact originals, participates in search and later summaries, and is limited to 200 retained pages per item. OCR uses Apple Vision on macOS, installed system OCR languages on Windows, and Tesseract on Linux; portable Linux users need the engine and language packs installed. OCR makes no cloud/model call. Summaries still follow the configured model and company-mode policy.
- Search matches and numbered answer sources can open the exact owned attachment page. Read-page buttons beside summaries make source checking faster; reading more pages marks an existing summary as needing regeneration.
- Individual attachment deletion offers immediate undo and a deletion-history restore. Restoring a leaf preserves later title, body, note and other-attachment edits instead of reverting the whole archive.
- Backup settings include folder, capacity and retention counts, with last-success time, directory usage and persistent failure notices. Defaults remain 7 daily and 3 each of other snapshot types, with a 10 GB capacity limit. Old backups are pruned only after a new backup succeeds; changing folders retains access to recent previous locations. Older snapshots migrate in staging before restore.
- Large uploads support pause, continue, cancel and reload/reselect resume. Previously uploaded chunks are verified with SHA256 before continuing. Per-operation leases prevent one submission from removing another submission’s staging file. Abandoned uploads expire after 24 hours, within the 4 GB staging limit. Files above 8 MB use 4 MB chunks; existing 1 GB/file and 2 GB/batch limits remain.
- Fix stale backup-status responses overwriting saved settings, early-upload cancellation leaving the composer busy, and empty upload panels blocking the send button.
