# Stellar Secretary v0.1.162

Select **Expand reading view** in item details to give the summary, full text and tables the whole window. Choose **Edit text** to change the title and Markdown source. Saving returns to the updated reading view at your previous position.

Press **Esc** in the editor to cancel your changes. Press **Esc** again while reading to return to the original item details and scroll position.

## 中文

在资料详情右上角点「展开阅读」，即可用整个窗口阅读摘要、正文和表格。点「编辑正文」可修改标题和 Markdown 原文，保存后会在之前的阅读位置显示更新后的内容。

编辑时按 Esc 可取消本次修改，继续全屏阅读。在阅读时再按 Esc，即可回到原来的详情窗和滚动位置。
