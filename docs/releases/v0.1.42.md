# Stellar Secretary v0.1.42

Append new materials and supplemental summaries to an existing archive.

- Choose **Append materials** in any archive detail to add text, pasted images or files to the same record. Originals, titles, manual tags, private quick notes and previous summaries are retained.
- Enable **Generate a supplemental summary after saving** to analyze the new batch with bounded prior-summary context. Dated supplemental summaries are appended; each batch can be retried without duplicating originals or summary entries.
- Preview images and PDFs, download batch originals, and search appended text and image descriptions. Backups restore complete batches. Deleting the parent archive removes its batch files too.
- Drafts survive cancel/reopen during the session; stale revisions and active processing prevent conflicting appends. Failed model calls preserve saved materials, and interrupted calls can be retried after restart.
- Each batch supports 20 files, 8 images and 50 MB. An archive supports 100 batches and 2 million characters of appended search text. Image/document overview limits still apply; originals are retained.

中文：归档详情新增「追加资料」，新文字、图片及文件按批次加入原归档，补充摘要按时间追加。支持原件预览下载、检索、备份恢复、失败重试与整组删除。

Validated with synthetic materials, incremental-summary and failure tests, backup restoration, deletion cleanup, browser interaction and frozen-app checks. The macOS installer is signed with Apple Developer ID and notarized.
