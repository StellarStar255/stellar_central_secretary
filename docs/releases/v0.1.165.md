# Stellar Secretary v0.1.165

Library chat can answer a new question in a single model call when complete short notes contain the necessary evidence. For supported cross-record questions, Secretary checks quoted passages against the originals and can search again when evidence is missing. Source excerpts can appear while the answer is being prepared.

Archived birthdays, dated appointments and simple facts in notes support more direct lookups. For two plans with explicit costs and a budget, Secretary can calculate and cite the comparison locally.

## 中文

首次提问时，如果几份简短笔记已经提供充分依据，秘书可在一次模型调用中综合作答。对于支持的跨资料问题，秘书会核对逐字摘录和引用的原文，依据不足时继续检索。等待完整答案期间可以先看到相关摘录。

归档生日、带日期的预约和笔记中的简单事实支持更多直接查询。两份方案列明费用且问题给出预算时，秘书可以在本地计算并引用比较结果。
