# Stellar Secretary v0.1.118

Continue desktop conversations from the iPhone, with the Mac keeping the shared history and doing the retrieval and model work.

- Add a native **Chat / 聊天** tab with the desktop conversation list, existing transcripts, new conversations, source citations, incremental answers and stop controls. Search’s **问知识库** opens the same shared chat.
- Derive phone questions from the canonical desktop transcript, including edited or ignored remembered conditions, context resets and recent cited sources. Messages and final answers appear in the same desktop conversation. Concurrent sends to a busy thread wait; separate conversations can run independently.
- Show protected local transcript caches immediately, including after an offline restart. Cache up to 100 recent messages in five threads, scoped to the paired Mac and pinned certificate; load older messages on demand.
- Persist offline messages for existing threads and retry after reconnection. Stable message IDs prevent a lost acknowledgement or process restart from running the same question twice. Accepted questions continue on the Mac while the phone app is closed.
- Preserve phone-submitted message pairs when an older desktop snapshot syncs, and honor deleted messages and conversations. Paired chat routes use the existing authenticated, certificate-pinned connection; model credentials and desktop settings stay on the Mac.

The updated iPhone development app has been installed for source trial. This release requires that companion update for the new Chat tab; updating the desktop does not replace an installed iPhone app. iOS 17 or later is required. There is no App Store or TestFlight distribution. Keep the Mac awake and its service running; internet remote access is not included.

Validation: 440 Python tests (11 platform-dependent skips), JavaScript conversation regressions including cross-language context parity, 19 native transport/cache tests, and all three iPhone simulator UI flows. The UI checks cover shared desktop context, bidirectional transcript updates, offline cache/outbox across restarts, retry deduplication, background completion, and existing pairing, search, tags, previews and original files. Signed device build installed and launched successfully. Release publication additionally requires three-platform CI builds, Mac signing/notarization and remote asset checksum verification.
