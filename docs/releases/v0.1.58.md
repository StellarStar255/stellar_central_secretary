# Stellar Secretary v0.1.58

Find, preview and manage archived material with fewer interruptions.

- Compact library results keep titles, sources and partial-content badges visible. Capture scope and timing remain available in expandable details.
- Search prioritizes title matches and highlights matching context. Filter by processing status, archive date or favorites; sort by recent views and browse bounded pages.
- A task panel shows individual capture and summary jobs, actionable failure explanations, cancellation and retry. Cancelling one job preserves its source and does not stop unrelated jobs.
- Single-click a library result for a side preview. Arrow keys and Enter navigate; double-click or Command/Control+Enter opens the original webpage. Full editing remains available from the preview.
- Favorite or pin material. Removal now moves items to a recycle bin with Undo and Restore. Permanent deletion requires a separate confirmation and cleans originals and conversation references. Backups retain recycle-bin content and metadata.

Validation: 197 Python tests (2 platform-specific skips on macOS), JavaScript regressions, and real-browser library, task, attachment editing, deletion and language checks. Windows and Ubuntu 22.04 CI verify packaged desktop applications and the library workflow before publication. The macOS download is Developer ID signed and notarized.
