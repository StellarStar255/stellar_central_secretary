# Stellar Secretary v0.1.101

Explicit archive instructions now save records during an ongoing conversation.

- Recognize clear Chinese save prefixes including **建档**, **建立档案**, **新建档案** and **存档**, alongside existing archive/save wording.
- Give explicit save instructions priority in Auto detect, Library chat and Ask modes, sending them through the actual archive endpoint instead of asking a model to describe a save.
- Preserve the original message and use the content after a command header as the title, making arrangements easier to identify and search.
- Keep questions such as “建档功能怎么用？” in the conversation flow. Quoted instructions and ordinary clarifications do not become save commands.
- Save failures retain the input and show an error without a success card.

Validation: JavaScript routing regressions and real-browser archive tests cover active conversations in all three modes, exact saved text, useful titles, searchability, reload persistence, archive-help questions and failed writes. Fixtures use synthetic material.

中文：修复明确输入“建档：……”却只得到模型文字回答、未真正保存的问题。自动识别、知识库对话和提问模式下，明确建档指令会直接入库，保留原文，并用安排正文生成标题；刷新后仍可查看和搜索。询问建档功能的消息仍按问题回答，保存失败时保留输入且不误报成功。
