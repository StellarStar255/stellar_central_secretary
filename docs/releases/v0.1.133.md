# Stellar Secretary v0.1.133

- Choose **Summary language** in **Models & Settings**. Automatic mode selects English or Simplified Chinese from the source text and uses the display language when the source is unclear. Select English or Simplified Chinese to use that language consistently.
- The setting applies to newly generated summaries, titles, categories, and tags. Use **Summarize again** on a saved record to regenerate its summary in the selected language.

## 中文

- 在「模型与设置 → 摘要语言」可选自动、简体中文或英文。自动模式根据资料正文识别中英文，无法判断时使用界面语言。固定选择英文或简体中文后，程序会用所选语言生成摘要。
- 该设置适用于新生成的摘要、标题、主题与标签。已有资料可点击「重新总结」，按当前设置生成摘要。
