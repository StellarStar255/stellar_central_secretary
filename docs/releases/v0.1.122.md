# Stellar Secretary v0.1.122

Fix ChatGPT conversation capture when a background Chrome tab shows a loading screen even after the conversation title appears.

- Let the capture tab finish rendering without switching to it or bringing Chrome to the front.
- Apply the change only to the tab opened for capture and restore normal browser behavior when capture finishes.

Validated with a Chrome regression that reproduces the hidden loading screen and checks that capture leaves the selected tab in place. Both affected conversations were captured again using the existing library, with text and summaries saved to their original records.

中文：修复后台 Chrome 标签页已显示 ChatGPT 会话标题、却一直停在加载画面并读到 0 条消息的问题。知识秘书现在可以在后台完成会话渲染和读取，采集结束后恢复该标签页的正常状态。已用原知识库重试两条受影响的会话，并确认正文和摘要写回原归档。
