# Stellar Secretary v0.1.44

Use custom model APIs without installing Codex or Claude CLI.

- Select **Custom model API (OpenAI-compatible)** and configure the base URL, model and key. A DeepSeek example is provided; compatible hosted and local Chat Completions services can be configured manually.
- API mode supports archive summaries, categories, source-backed questions, grouped materials and supplemental summaries. Optional image input and JSON output, plus configurable output limits and token parameter names, accommodate different models.
- Text-only models retain image originals and explicitly label images as unread. Existing image descriptions are preserved when a text-only summary is generated.
- Keys are stored in a separate local file, never returned to the UI or included in knowledge-library backups. Changing an endpoint requires re-entering the key. HTTP requests do not follow redirects.
- Connection tests send only a short test message. Requests run in isolated cancellable workers; packaged Windows workers restore inherited I/O pipes without opening console windows.
- Preserve backend edits while a settings refresh is in progress.

中文：支持自定义 OpenAI 兼容模型 API，可配置地址、模型和密钥，不再必须安装 CLI；支持摘要、问答、图片输入与追加摘要。密钥独立本机保存，不进入知识库备份。

Validated against a synthetic local API provider with real HTTP and worker processes, UI configuration, image capability handling, secret masking, backup exclusion, redirect protection and frozen-app checks. Third-party accounts require the user's own credentials. The macOS installer is signed with Apple Developer ID and notarized.
