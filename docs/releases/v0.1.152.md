# Stellar Secretary v0.1.152

The desktop archive reader separates notes from attachments in grouped captures. Expand an attachment to read its extracted text or open the matching PDF page. Background updates preserve the expanded attachment, scroll position and keyboard focus.

Standalone and grouped documents now display page breaks, headings, lists and aligned text. Invoice fields are grouped for easier comparison. Word extraction preserves paragraph and cell boundaries, including empty columns. Markdown code blocks retain blank lines and indentation. The original extracted text remains available for verification.

## 中文

组合归档现在单独展示备注和各份附件。展开附件即可阅读提取文字，也可打开对应 PDF 原页。后台刷新时会保留已展开的附件、阅读位置和键盘焦点。

普通文件和组合附件都支持按页码、标题和列表阅读，发票中的购销双方信息按字段排列。Word 提取保留段落和空列，Markdown 代码块保留连续空行与缩进，原始文本可展开核对。旧 Word 归档如需找回提取时丢失的列位置，需要重新解析原文件。
