# Stellar Secretary v0.1.41

Keep the annotation submitted alongside a link, even when its webpage cannot be read.

- Save accompanying text as a searchable annotation on the same link record and use it for a descriptive title.
- Generate summaries and categories from annotations when no webpage text is available, with an explicit user-annotation-only scope label.
- Preserve annotations separately from webpage text during later browser capture and backup restoration. Repeated submissions enrich the existing record without replacing its webpage body.
- Links with annotations are saved immediately after the direct fetch attempt; browser login/capture remains available on demand.

中文：修复「说明文字＋链接」只保存链接的问题。无法读取网页也能根据自己的文字归档、搜索及整理，明确区分用户说明与网页正文，后续读取网页不会覆盖说明。

Validated using synthetic inaccessible links, browser submission and reload, annotation search, repeated submissions, later captures and backup restoration. The macOS package is signed with Apple Developer ID and notarized.
