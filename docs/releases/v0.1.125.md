# Stellar Secretary v0.1.125

- In the image viewer, two-finger scrolling pans the image. Pinching changes zoom. The viewer hides the cursor during two-finger panning and applies position updates once per frame.
- Images pasted into chat or the append-materials dialog now use the same on-device naming as quick notes. Names such as `image.png` can be replaced with a name based on recognized text or image category.

## 中文

- 图片预览支持双指滑动平移、捏合缩放。双指平移时暂时隐藏光标，并按屏幕帧更新图片位置。
- 聊天框和「追加资料」也支持为剪贴板图片自动命名。图片使用 `image.png` 等通用名时，会尝试从本机识别出的文字或图像类别生成文件名。
