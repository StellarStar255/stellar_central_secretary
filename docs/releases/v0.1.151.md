# Stellar Secretary v0.1.151

Desktop chat cards for iPhone captures now show the archive summary, including on earlier receipts. The status follows the active summary job from queueing through processing and completion.

The iPhone companion source lets you select files saved from several shares, add photos and a note, and send them as one archive. Automatic summary settings are accessible from Quick Capture. The iPhone app is distributed separately.

## 中文

手机归档的摘要现在直接显示在桌面聊天卡片里，以前的归档回执也能看到。摘要任务排队和处理期间，卡片会显示对应状态，完成后显示摘要。

iPhone 配套版源码支持勾选多次分享暂存的文件，再添加照片和文字，一起保存为一份归档。「随手归档」页面可直接进入自动摘要设置。iPhone 应用单独分发。
