# Stellar Secretary v0.1.113

Connect the iPhone companion wirelessly, resume faster after switching apps, and archive local file locations without importing whole folders.

- Add a Wi-Fi/AWDL carrier and an independent CoreBluetooth data carrier on Mac and iPhone. Preserve end-to-end certificate pinning and desktop-approved device credentials. Remember the last verified carrier and keep USB link-local addresses from taking priority.
- Automatically reconnect using the saved pairing. Reuse a working pinned TLS session after a short app switch; refresh genuinely stale sessions and try the previously verified Bluetooth peer before scanning again. Reuse authenticated gateway connections and retry known addresses while device discovery continues.
- Handle Windows exclusive-port conflicts by choosing a free gateway port when the saved port is unavailable. Explicitly configured ports still report errors.
- Support private IPv6 and alternate local endpoints, refresh discovery after network changes, and reuse the mobile gateway port when possible. VPN and system proxy settings remain unchanged.
- Process phone images using local OCR and the desktop's existing automatic-analysis setting. Show mobile captures in the active desktop chat, preserve original attachments, and deduplicate retries and chat receipts.
- Archive a file or folder location as a shortcut. Double-click a shortcut to open the recorded location; executable and script files are revealed rather than run. Preserve explicit question mode and report unavailable paths clearly.

The iPhone companion remains a development installation for iOS 17 or later; this desktop release does not include an App Store or TestFlight distribution. Keep the Mac awake with phone connection enabled. Bluetooth is useful when local IP routing is unavailable; large attachments can transfer more slowly than over Wi-Fi. Wi-Fi-only reliability depends on the network; successful wireless access on the tested iPhone was verified through the Bluetooth carrier.

Validation: native BLE framing and malformed-length checks; byte-preserving relay and pinned TLS reuse tests; iPhone simulator pairing, foreground connection reuse, offline outbox and automatic retry; physical iPhone Bluetooth requests and background/foreground recovery; mobile and local-path UI checks; full Python and JavaScript regression suites. Three-platform builds and a signed, notarized Mac package are required before publication.
