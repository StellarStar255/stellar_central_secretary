# Stellar Secretary v0.1.46

Archive command snippets and knowledge text directly from the composer.

- Auto detect now saves commands and ordinary declarative text as searchable notes. Clear questions continue using source-backed library retrieval.
- Choose **Archive text / commands** to save any text explicitly, including questions; choose **Ask about this material** to ask explicitly. The composer explains the default behavior.
- Preserve command lines, indentation and embedded URLs as material. Commands are never executed, and command URLs do not trigger webpage capture.
- Plain-text notes receive a title from their first content line before optional AI summarization. Text-only submissions also work in grouped archive mode.
- Existing links, attachments, grouped materials and archive summaries remain available.

中文：修复自动识别把纯文字和命令一律当成提问的问题。命令和普通知识文字默认直接归档、原文可搜索；明确的问题才检索，也可手动指定归档或提问。命令不会执行，命令里的链接不会自动抓取。

Validated with composer routing regression tests and a real browser using isolated synthetic material: literal command preservation, searchable persistent notes, no execution or URL fetch, and explicit archive/question overrides.
