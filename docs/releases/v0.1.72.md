# Stellar Secretary v0.1.72

Improve recovery, editing, local video playback, backups and large attachments.

- Updates retain the previous program until the new process passes version, library and desktop health checks. Failed installation/startup or a version mismatch rolls back program files without reverting library data. Recovery startup is checked too; an incomplete recovery reports the preserved backup location.
- Title, body and quick-note edits save before closing or switching items. Local drafts survive failed saves, concurrent edits are checked, and explicit Cancel/Escape discards unsaved editor changes.
- Video cards show decoded covers and duration. Playback supports fullscreen and local resume, with a native silent cover decoder and player on Windows/Linux when embedded-browser codecs are unavailable.
- Local backups run daily while the app is open and before upgrades. Settings provides manual backup and restore; restoring first saves the current library. Retention is 7 daily snapshots and 3 each of manual, pre-upgrade and pre-restore snapshots. Database, originals, notes and conversations are included; browser sessions and API-key files are excluded.
- Attachments upload in bounded 4 MB chunks above 8 MB, supporting 1 GB per file and 2 GB per batch. Repeated contents are skipped within a submission and later additions to the same archive. Downloads, ranges, deletion recovery and backup/import paths stream from disk.
- PDFs above 50 MB now read only the first 5 pages from disk, with up to 8,000 characters per page, total-page/read-scope labels and an intact original. Scanned, encrypted or unreadable files report the reason. Partial text is never labeled a full-document summary. Large PDF thumbnails and byte-range viewing avoid whole-file reads. Other formats retain the 50 MB automatic-extraction limit; edited-file save-back retains its 50 MB limit.
