# Stellar Secretary v0.1.136

- Windows updates retry when the previous installation is temporarily locked. If the folder stays locked, the updater can start the previous version from a recovery copy using the existing library. Settings show the recovery result, offer the installer log when available, and explain how to repair the original installation.
- The macOS settings window keeps the title and Save settings button visible while the controls scroll, including at large interface font sizes.
- Expand **Evidence for this answer** to see cited excerpts, conversation conditions, and the PDF pages supplied for the answer.
- With the updated iPhone companion and desktop app, uploads show bytes received by the computer. A failed batch of attachments can be retried individually.

- When a library preview title is saving, opening the full record waits for the save so it shows the updated title.
