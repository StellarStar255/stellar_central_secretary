# Stellar Secretary v0.1.32

修复通用网页在读取过程中无法正常加载、停止读取后才恢复的问题。

- 原因是请求拦截依赖采集线程持续处理事件，等待确认时该线程暂停，导致页面的接口及嵌入页面请求挂起。
- 移除通用网页的请求拦截。等待登录或确认、读取正文期间，浏览器可继续加载资源、调用接口及响应用户跳转。
- 保留起始链接和采集页面地址检查，额外核对快照中的实际地址，防止页面跳转后错存其他内容。
- 已用本地动态网页复现旧版问题，并验证修复后异步接口、嵌入内容、点击跳转、采集中刷新与正文采集可同时正常工作。
- 原有资料、手动标签、图文速记和登录目录保留。

English: Fix webpages that stalled during capture and resumed only after Stop. Generic capture no longer intercepts browser requests while waiting for confirmation. APIs, iframes and navigation remain functional. Target-address checks are retained and the snapshot's actual URL is checked before saving.

macOS 安装包使用 Apple Developer ID 签名，完成苹果公证及票据装订。
