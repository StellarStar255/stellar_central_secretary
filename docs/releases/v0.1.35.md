# Stellar Secretary v0.1.35

支持通过浏览器读取用户主动提交的本地网页，修复本地动态查看器被“仅支持公开网页地址”拦截的问题。

- 支持 localhost、IPv4 / IPv6 回环地址，保留完整代理路径、查询参数和片段。
- 本地链接进入浏览器确认读取流程，不再先用后台抓取并显示公网限制错误。
- 本地正文及嵌入页读取限定于原始主机、协议和端口；公网目标不能转为本地采集。
- 后台直接抓取继续仅允许公网地址；不扫描端口、不自动读取其他本地服务。
- 验证动态加载、真实采集子进程及打包后采集，跳过普通输入草稿；测试使用临时模拟页面，不访问用户的实际服务，也不调用模型。

English: Browser-confirmed capture now supports explicitly submitted localhost and IPv4/IPv6 loopback pages, including dynamic local viewers. Original proxy paths, queries and fragments are retained. Local capture stays within the submitted origin; automatic server fetching remains public-only.

本地服务必须与采集浏览器运行于同一台电脑且保持启动。macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
