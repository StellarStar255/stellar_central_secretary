# Stellar Secretary v0.1.9

修复新版 ChatGPT 页面上的折线图仍被提取为年份与数值的问题。

- 支持新版 search-unit 消息容器，并以稳定消息 ID 收集完整会话。
- 角色标题 DOM 兜底路径同样保留图形，不再直接退回纯文本。
- 保存 Recharts 图表的曲线、坐标、名称和按钮式彩色图例。
- 图表原始数据与说明收进可展开区域，保留检索能力。
- 诊断记录页面 SVG 图表数与成功保存数，便于发现漏采。
- 已在真实页面上验证六条曲线、六个图例及完整会话采集；新增相同 DOM 结构的独立浏览器回归测试。

macOS 安装包使用 Developer ID Application: Qiliang Huang (3QCL9WNFBB) 签名，通过苹果公证及票据装订。Windows 安装包未做代码签名。附件包含 SHA256SUMS.txt。

可从「模型与设置 → 版本与升级」升级。旧归档需要重新读取才能补回图形；图形为静态快照，原图交互请打开原链接。浏览器扩展用户请下载新版扩展并重新加载。
