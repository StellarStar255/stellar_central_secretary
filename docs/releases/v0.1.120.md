# Stellar Secretary v0.1.120

Save several computers on an iPhone and switch between work and home libraries without pairing again.

- Add **连接 → 添加电脑**, a saved-computer list, local display names, explicit selection and independent removal. The phone can save ten computers; each desktop already supports ten independently approved phones. Current-computer labels appear in capture, chat and search.
- Preserve existing single-computer credentials and caches during an in-place phone upgrade. Keep each computer's library/chat caches and offline queues separate by server ID and pinned certificate. Switching preserves unsent editor contents in memory; queued content survives restarts and is delivered only to its original computer.
- Fence late connection and query results when switching. Finish or cancel an upload, message submission or download before changing computers. A desktop answer already accepted continues on that desktop. Removing the selected computer leaves selection empty rather than silently choosing another destination.
- Allow cancelling an added pairing and restore the previous computer. Rescanning an existing computer reuses its approved credential; a revoked credential requires fresh desktop approval. Improve restored chat scrolling and keyboard dismissal.

This feature requires the updated iPhone development app. The desktop update does not replace the phone app. The development build was installed in place on the connected iPhone, and its existing pairing reconnected successfully. This is not an App Store or TestFlight distribution. Libraries remain independent; multi-computer pairing does not add cloud synchronization or internet remote access.

Validation before release: 24 native storage/transport/TLS tests, 21 mobile gateway tests and four native simulator UI scenarios passed. The scenarios cover existing capture/search/attachments, scanner behavior, shared-chat recovery, multiple approved computers, cache isolation with identical chat IDs, offline queues, editor restoration, cancelled additions and individual removal. The signed iPhone development build launched and reconnected on the physical phone. Full interactive multi-computer testing on that phone was limited by unavailable screen mirroring; the complete switching flow was verified in the simulator. Publication additionally requires full Python/JavaScript regressions, three-platform CI, Mac signing/notarization and remote installer checksum verification.
