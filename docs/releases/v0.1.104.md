# Stellar Secretary v0.1.104

Open cited material directly from answer text, with quieter answer actions.

- Move **Check again** and **Retry answer** beside **Copy answer** as small, borderless text actions. Keep keyboard focus, hover feedback and the existing recheck behavior.
- Make supported citation numbers such as `[2]` and `【2】` clickable in completed answers. Open the matching source immediately and locate its cited passage; PDF references retain their page navigation.
- Resolve citation numbers within each answer, including nonconsecutive numbers. Unknown numbers remain text. Code samples, existing links and chart markup are not converted into citation controls.
- Show the current unavailable-source explanation when a cited record is in the recycle bin or has been removed.

Validation: JavaScript regressions, full Python tests, and isolated browser checks for recheck success/failure, inline citations, keyboard activation, source scoping, PDF navigation, code/link exclusions and recycle-bin state.

中文：将“重新核对／重试回答”改为“复制回答”旁的小号无边框入口。正文中的引用编号现在可以单击打开对应资料并定位引用片段，PDF 引用跳到对应页；编号按各自回答匹配，代码和普通链接不会误转换，回收站资料会提示当前状态。
