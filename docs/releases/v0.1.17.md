# Stellar Secretary v0.1.17

修复长会话因等待完整历史加载而无法归档的问题，默认快速读取最近片段。

- 「模型与设置 → 会话读取范围」可选择最近最多 20 轮、当前已加载内容、完整会话，默认选择最近片段。
- 最近片段从会话末尾开始，在有限滚动次数内收集，不再强制确认历史最顶部，也不等待整页绘图或历史内容完全稳定。若可读取内容少于 20 轮，按实际取得内容保存并标注消息数量。
- 部分归档在卡片、正文和摘要中标明范围，避免被误认为完整会话。已有完整正文保持不变，最近片段另存；最近片段重读前保留历史快照。
- 部分摘要使用有界输入，超长片段最多读取最近 4 万字符；已有普通文件和完整会话的摘要方式保留。
- 保留后台打开、仅关闭任务新开网页、菜单栏及 Dock 状态功能。

已验证持续加载的历史、范围限制、当前内容不滚动、完整正文保护、部分摘要预算与设置持久化；在本机真实长会话验证最近片段读取成功。

macOS 安装包已通过 Apple Developer ID 签名、公证和票据装订。附件提供两平台安装包及 SHA256SUMS.txt，可在安装版中一键升级。
