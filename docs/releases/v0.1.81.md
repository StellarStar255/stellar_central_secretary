# Stellar Secretary v0.1.81

Press Command-K again to close library search, and follow a photo-to-library example in the README.

- Command-K on macOS and Control-K toggle the search dialog: open and focus search when closed, or close it when already open. Closing uses the existing draft-saving path, and reopening keeps the search keywords. Held keys do not repeatedly open and close it; a child modal retains keyboard ownership until dismissed.
- Add a four-screenshot example to both English and Chinese READMEs: submit two HEIC photos of a paper fitness-band manual, review the summary and attachments, enlarge a photo, then find the material again by keyword. English descriptions accompany the original screenshots.

Validation: real-browser library regression covers both shortcuts, repeated-key suppression, retained keywords and title-draft saving on close. Chat UI regression passed.
