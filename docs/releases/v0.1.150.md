# Stellar Secretary v0.1.150

Desktop upgrades check for active work before shutdown and restore the previous Mac application if installation fails. Backup verification checks restored chat data and keeps the last successful manual backup when a later check fails. Browser startup failures include additional diagnostics.

The companion source now includes an iOS share extension. It can send a file directly to the selected Mac and keep a local copy when delivery fails. The iPhone app is distributed separately.

## 中文

桌面端在升级退出前检查活动任务。Mac 安装失败时会恢复旧应用。备份验证会检查还原后的聊天数据，后续检查失败时保留上一次成功的手动备份。浏览器启动失败时可查看更详细的诊断信息。

本次源码包含 iOS 分享扩展，可以从微信等应用直接向选中的 Mac 发送文件，发送失败时保留手机副本。iPhone 版独立分发。
