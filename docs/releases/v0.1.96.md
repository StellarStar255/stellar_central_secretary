# Stellar Secretary v0.1.96

Compact reference cards with discreet actions that respond immediately.

- Reference cards now use a narrower layout: titles occupy at most two lines, with a single muted excerpt line. Full excerpts remain available for locating the cited text.
- Small, unfilled **View item** and **Original ↗** text actions sit below the excerpt. View item opens the archive immediately; Original opens a valid saved HTTP(S) URL directly. Local notes omit the original-link action. PDF references retain page navigation.
- The card body retains single-click viewing and quick double-click opening of linked material. Its click-disambiguation wait is reduced from 400 to 200 ms. Keyboard activation and the explicit text actions do not use that wait.
- Original-link actions retain recent-view tracking. References from older chats still reload their link metadata from the archive.
- The project workflow now records the user's preference: start the latest source with the existing library for a trial before release; proceed once that version has been tried and the user requests publication.

Validation: chat UI regression, real-browser compact-card dimensions, immediate View item request, direct original-link opening, quick double-click, local notes, PDF page routing, reloaded older references, full conversation/catalog/streaming regression and the unit suite. Browser fixtures use synthetic records; private screenshots and library contents are not shipped.
