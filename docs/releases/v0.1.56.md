# Stellar Secretary v0.1.56

Double-click a linked archive card in chat to open its original webpage.

- Double-click opens the original HTTP/HTTPS link in a browser, retaining query parameters and fragments.
- Single-click still opens item details; keyboard activation continues to open details immediately.
- A short mouse-click delay prevents the details dialog from intercepting the second click. Cards without a webpage link keep their existing behavior.
- Add a translated hover hint describing both actions.

Validation: real Chrome checks confirmed that double-click opens the exact source URL without opening or requesting item details. Single-click and keyboard activation still open details. JavaScript UI regressions passed.
