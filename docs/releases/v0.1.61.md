# Stellar Secretary v0.1.61

Capture intranet pages in your browser and keep automatic summaries with a confirmed model destination.

- Browser capture accepts the submitted intranet, VPN or proxy-DNS origin using the browser's network configuration. After login, you can confirm a different page within the same origin. Background HTTP fetching retains its public-address restrictions, including redirects.
- DNS and browser-proxy failures give specific next steps. The regular-browser extension guide now covers already signed-in websites and company-network pages.
- **Company mode is off by default.** When off, summaries and questions follow your normal model settings without an extra confirmation. The switch is saved on this computer. Enabling company mode activates the following model-service checks.
- In company mode, browser-captured material, imported webpage text and marked company material require a one-time model-service acknowledgement before summaries, supplemental summaries or library questions can send their content to a model. After confirmation, future material follows the automatic-summary setting.
- Changing the model backend or API configuration requires confirmation again. Confirmation can be revoked. External CLI account or service changes require you to revoke and confirm again; the app cannot verify company authorization.
- Reading a webpage no longer forces a summary when automatic summarization is off. Existing source text, summaries and notes remain available when confirmation is declined or revoked.
- Item details read source content and task-busy status together, avoiding stale content being reported as a completed task.
- Backups preserve company-material markers without transferring model-service confirmation. Ordinary files and text can be marked as company material from their details.

Validation: 217 unit tests, JavaScript regressions, real-browser intranet and login-redirect checks, consent cancellation and revocation checks, and frozen-application checks with a synthetic local model provider. Windows and Linux run the new browser workflows before publication.
