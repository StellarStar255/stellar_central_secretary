# Stellar Secretary v0.1.85

Chat directly with your saved library, follow up naturally, and find related material with optional local semantic search.

- **Library chat:** select the dedicated composer mode or the welcome shortcut. Recent successful question/answer pairs help resolve follow-ups; new chats clear context, and saved conversations retain their input mode after a reload. Text and URLs in this mode are questions rather than new archives.
- **Grounded retrieval:** the selected Codex / Claude / Gemini CLI or compatible API plans keyword queries, searches saved material, and answers from retrieved passages with clickable sources and attachment/page information where available. Missing content is disclosed. Company-data confirmation applies to both historical and newly retrieved sources.
- **Optional local semantic search:** connect a local Ollama embedding model and combine vector matches with keyword retrieval. Existing material is indexed in background batches; edits, title changes, trash and deletion invalidate affected vectors. SQLite stores the cache without a separate vector database or additional Python ML dependencies.
- **Index controls:** test the embedding service, inspect progress/errors, enable or disable search, adjust the similarity threshold, and rebuild. Incomplete indexing and embedding-service failures are disclosed while keyword search remains available. Embedding requests accept loopback URLs only, bypass proxies and reject redirects.

Setup: install/start Ollama and download an embedding model, for example `ollama pull bge-m3`. Then open **Models & settings → Local semantic search**, test the service and enable it. This is optional and disabled by default; the app does not download models. Answers continue to use your existing model settings. Local CLI authentication is separate from desktop-app login; hosted CLI/API calls still use the corresponding online service and account allowance.

Validation: 332 unit tests passed (10 platform-specific/opt-in skips), plus chat UI regression; real-browser checks for follow-up context, reload persistence, clickable citations, semantic-only retrieval, background backfill, service-failure keyword fallback, rebuild, main-settings save and Chinese/English display. Model and embedding outputs in these integration checks are deterministic fixtures; actual model quality and account authentication depend on the configured services. Packaged builds are checked separately before publication.

中文：本版新增「知识库对话」，可直接询问已保存资料并连续追问，回答附可打开的来源与附件页码。对话模式刷新后保留，问题与 URL 不会被误归档；旧的归档方式和「仅归档」优先行为保留。检索先结合对话生成关键词，再依据实际命中的资料回答，公司资料沿用既有模型服务确认。

另加入可选的本地语义检索：通过本机 Ollama 嵌入模型生成向量，与关键词结果合并；旧资料自动补建，新增、修改、改标题、回收站及删除同步维护索引。设置页提供测试、进度、错误、开关、阈值和重建。嵌入服务不可用时保留关键词检索并提示回退。索引保存在 SQLite，无需独立向量数据库；仅连接本机回环地址，不使用代理或跟随重定向。

语义检索默认关闭，程序不会自动安装或下载模型。使用前请安装并启动 Ollama，运行 `ollama pull bge-m3`，再进入「模型与设置 → 本地语义检索」测试并启用。回答继续使用原有 Codex / Claude / Gemini / API 配置。已通过合成资料与固定模型/向量回复的自动化验证；真实模型语义效果与账号调用需由实际配置的服务提供。
