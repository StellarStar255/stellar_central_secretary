# Stellar Secretary v0.1.119

Fix browser capture failing before conversation text can be read, with `Browser.setDownloadBehavior: Browser context management is not supported`.

- Attach to the dedicated Chrome session while preserving its existing download, focus, font and media settings. Apply the same connection behavior to ChatGPT capture, ordinary webpage capture and dedicated-browser cleanup.
- Require Playwright 1.60 or later for the supported connection option.
- Add a real Chrome regression using a temporary profile and synthetic content, covering attachment without an open window, conversation extraction, webpage extraction, task-tab cleanup and reconnecting to an empty browser.

The affected conversation was successfully captured during source trial. Existing capture-range settings still apply; a recent or loaded-content capture is marked as partial.

Validation: 441 Python tests (11 platform-dependent skips), JavaScript conversation regressions, real Chrome conversation/webpage capture and dynamic-page worker checks, and packaged macOS smoke checks passed. Publication additionally requires successful three-platform CI, Mac signing/notarization and remote asset checksum verification.
