# Stellar Secretary v0.1.143

- Windows startup can recover when a saved library folder or its database is unavailable. Retry the original folder, select an existing library, or open a separate temporary library.
- Backup settings display the warning area only when there is a warning or error.
- Successful upgrades remove old installer downloads and redundant program copies while retaining rollback material and logs.

## 中文

- Windows 找不到已设置的记忆目录或打不开数据库时，可以在启动窗口重试、选择已有知识库，或打开独立的临时知识库。
- 备份设置有警告或错误时才显示提示区。
- 升级成功后清理旧安装包和多余的程序副本，并保留回滚材料和日志。
