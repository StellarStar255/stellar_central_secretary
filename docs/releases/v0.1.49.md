# Stellar Secretary v0.1.49

Open and edit archived attachments without downloading and reimporting them.

- Common documents, spreadsheets, PDFs, text and images can open in the default local application or be revealed in their folder. Supports standalone originals, grouped attachments and appended batches. A compatible application must be installed.
- Compact editing-folder identifiers reduce path length for long document names. Editing copies keep their original filenames. Reopening preserves local changes; archive contents change only after **Save changes to archive** is clicked.
- Save-back updates the same archive/batch, downloadable original and searchable text. Attachment IDs, unrelated files, parent originals, titles, manual tags and quick notes are preserved. Existing summaries are flagged as outdated rather than regenerated automatically.
- Previous file versions and relevant summary metadata are retained locally under the archive’s editing directory. Deleting an archive cleans up editing copies and history. ZIP backups include the latest committed originals; unsaved copies and local edit history are not included.
- Busy archives, conflicting attachment versions, active writes and indexing limits prevent unsafe replacement while retaining the local editing file. File/SQLite updates roll back on runtime failure.
- Executable/script file types retain download-only handling. Browser PDF/image viewing and original download links remain available.

中文：附件新增默认程序打开、在文件夹中显示，以及保存修改回原归档/追加批次。保留本机编辑副本和修改前版本，更新搜索和下载原件，不自动重跑摘要；父原件及其他附件保持不变。

Validated with synthetic workbook/text/PDF fixtures: working-copy preservation, same-batch save-back, stable attachment IDs, search and backup content, version conflicts, rollback on database failure, metadata filename collisions, deletion cleanup, POST authentication and bilingual browser controls. External application launching is mocked in UI tests; installed file associations determine which application opens each format.
