# Stellar Secretary v0.1.59

Click an archived image to view it in your system's default image application.

- Image thumbnails in chat, grouped archive attachments and appended materials now open their named local file through the system default application.
- Mouse clicks and keyboard activation use the same authenticated local open action, without opening a browser page.
- Image downloads and explicit PDF browser viewing remain available. Opening an image preserves the archived original and any existing local edits.

Validation: JavaScript UI regressions and real-browser checks verify native-open requests for chat, archive and appended images, correct local filenames and bytes, keyboard activation, and no extra browser pages. Windows and Ubuntu 22.04 run these image workflows alongside packaged desktop checks before publication. The macOS download is Developer ID signed and notarized.

中文：点击聊天、资料详情或追加附件中的图片缩略图，现在使用系统默认看图程序打开，不再跳转网页。支持键盘操作，保留下载入口和原图内容；PDF 的浏览器查看保持不变。
