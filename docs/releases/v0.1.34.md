# Stellar Secretary v0.1.34

改进飞书类富文档页面的正文提取，修复页面有内容却持续提示未取得稳定正文的问题。

- 识别结构化文档编辑区中的已显示正文，避免把整份富文档当成普通输入草稿排除。
- 支持无布局盒的 display:contents 容器和开放 Shadow DOM 中的正文。
- 确认后可追加最多 4 个可见同源或飞书/Lark 文档域嵌入页面的已加载文字；仍检查实际地址和字符预算。
- 跳过隐藏、小尺寸、无关跨域、登录验证框及评论/普通表单草稿。
- 可读正文不再因非阻塞的保存图标或少量实时状态文字变化而一直等待。
- 超时错误补充可读字符数和嵌入页数量，不记录正文到诊断提示中。
- 使用模拟富文档、可编辑容器、Shadow DOM、嵌入页面及持续更新状态做真实 Chrome 回归；未访问或上传用户的飞书正文。

English: Improve extraction of Feishu-style rich documents, display:contents and open shadow roots. Capture can include bounded visible same-origin or Feishu/Lark document frames, while excluding ordinary input/comment drafts and hidden or unrelated frames. Nonblocking save indicators and small status changes no longer prevent readable text capture.

仅归档已加载文字，不自动展开全部历史或读取画布图片文字。macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
