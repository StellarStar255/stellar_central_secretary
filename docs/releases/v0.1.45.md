# Stellar Secretary v0.1.45

Windows now includes a native desktop window, alongside browser mode.

- Switch between **desktop** and **browser** in **Models & settings → Interface mode** or the notification-area menu. Both modes share the same library, settings and conversation history; the selected mode is remembered.
- New Windows installations start in desktop mode. The bundled Chromium engine requires no separate WebView2 installation. Supports Windows 10 1809 and later, and Windows 11 x64.
- Close the window to keep the service running in the notification area. Restore it from the tray menu or by reopening the app, reusing the existing window and service.
- Tray icons show starting, ready, busy and error states. The menu provides desktop/browser access, data folder, logs and quit controls. Quitting during active tasks offers an explicit stop-and-quit choice.
- External links open in the regular browser; downloads use a native save dialog. Originals and API credentials continue using the same local data directory.
- Windows UI validation runs against both source and frozen builds using isolated synthetic data, checking mode switching, shared history and library, close/reopen behavior and shutdown.

中文：Windows 版新增独立桌面窗口与系统托盘，可在设置或托盘菜单自由切换网页/桌面模式，共用知识库与对话记录并记住选择。关闭窗口后继续在托盘运行，重新启动会恢复原窗口。内置 Chromium，无需另装 WebView2。
