# Stellar Secretary v0.1.67

Play video attachments in the application and save title edits by clicking a blank area.

- Video cards in the attachment overview and library preview open an in-app player. Original and supplemental videos use the same entry point; playback does not open a browser tab or download the file automatically.
- macOS and browser mode use the built-in HTML video controls. Windows and Linux desktop hosts use Qt Multimedia independently of Qt WebEngine’s codec configuration, with playback/pause, seeking and volume controls. Closing the player stops playback. Default-app and original-download options remain available for unreadable or unsupported codecs.
- Local video preview endpoints support byte-range reads for seeking. Existing video attachments are recognized by filename; originals and archive contents are preserved. Playback does not extract subtitles, transcribe audio or send video contents to a model.
- Clicking a blank area outside the title editor saves the modified title in both full details and the library preview. Save/Enter, Cancel and Escape retain their explicit behavior. Unchanged titles avoid a write; failed saves keep the draft available for retry and duplicate submissions are blocked.
- Add a synthetic H.264 fixture, original/bundle/supplemental range tests, actual browser playback and title-edit regressions, actual macOS WKWebView playback checks, and source/frozen Windows native decoder checks.

Includes all v0.1.65 Windows automatic-update corrections. If an older Windows version cannot launch its updater, run this version’s setup file once in the existing installation directory. Local library data remains outside the application folder.
