# Stellar Secretary v0.1.115

Make the iPhone library faster to reopen and easier to edit, with inline image previews and individual tag controls.

- Show locally cached library results immediately, including after an offline restart. Reuse fresh results for a minute and refresh older results in the background. Failed refreshes retain the previous list; successful phone captures invalidate freshness. Cache metadata is scoped to the paired Mac and pinned certificate and excluded from backup.
- Rebuild stale TLS, radio relays and service discovery after at least 20 seconds in the background. Cancel old connection attempts and ignore their late results. Short app switches retain working TLS connections; active uploads/questions are allowed to finish before the pending rebuild.
- Put original links and archived file access at the top of record details. Edit titles separately; display tags as wrapping chips, add tags individually and confirm removal before syncing it. Edits detect concurrent desktop changes and preserve the phone draft on failure.
- Append photos or files (up to 10 MB each) to an existing record, preserving its originals. Stable request IDs deduplicate retries. Mobile file access is limited to authenticated attachments belonging to that record.
- Automatically show image previews inline without a separate view button. Generate JPEG derivatives no larger than 96 KB while keeping the original bytes unchanged. Full original downloads have byte progress and cancellation; completed files are reused from a protected, bounded phone cache and invalidated when the archived file changes. First-time full downloads over Bluetooth remain bandwidth-limited.
- Keep long source text collapsed below the main actions and summary. Background image loading does not block metadata editing.

The iPhone companion remains a development installation for iOS 17 or later. These phone features require the updated companion; a desktop update alone does not replace an installed iPhone app. There is no App Store or TestFlight distribution in this release. The updated development build has been installed on the existing iPhone and tried by the user.

Validation: native TLS/relay and cache tests; the complete iPhone simulator pairing, short/long background recovery, offline outbox, cached list, metadata editing, tag add/remove confirmation, automatic image display, original-file cache and cancellation flow; mobile API tests covering conflicts, revocation, parent-owned downloads, retry deduplication, preview bounds and byte-identical originals; full Python and JavaScript regression suites. Desktop publication requires three-platform builds and a signed, notarized Mac package, with all remote assets verified.
