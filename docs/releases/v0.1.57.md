# Stellar Secretary v0.1.57

Double-click linked results in the knowledge library to open their original webpages.

- Extend chat card double-click navigation to the knowledge library and filtered search results.
- Single-click and keyboard activation still open item details. Cards without a webpage link keep their existing behavior.
- Preserve source query parameters and fragments, with the same translated action hint as chat cards.

Validation: real Chrome verified the library list and filtered search results, including exact original URLs, no unwanted details on double-click, retained single-click details, and existing chat/keyboard behavior. JavaScript UI regressions passed.
