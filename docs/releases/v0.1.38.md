# Stellar Secretary v0.1.38

增加正文专用字号快捷键，界面按钮和侧栏保持原字号。

- ⌘ +（或 ⌘ =）放大正文，⌘ - 缩小正文，⌘ 0 恢复 100%；Windows / Linux 可使用 Ctrl。
- 每次调整 10%，范围 70–200%；对话文字、资料摘要、正文及阅读器文字按比例变化。
- 按钮、侧栏、菜单、输入框及页面布局尺寸不随这些快捷键变化，不使用浏览器整页缩放。
- 正文缩放单独保存在本机，刷新后恢复；与设置中的全局界面字号独立，可在设置中恢复正文大小。
- 验证真实键盘事件、刷新恢复、对话与资料详情、快速连续调整、上下限及保存失败回退，保留原文和草稿。

English: Cmd + / = and Cmd - resize reading content only; Cmd 0 resets it. Ctrl works on Windows/Linux. Content scaling is saved separately from the global interface font size, with controls and composer text unchanged.

macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
