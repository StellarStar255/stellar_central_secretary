# Stellar Secretary v0.1.8

修复会话归档中表格变成散乱文字、图表只剩年份和数值的问题。

- 采集时保留表格行列结构；阅读时支持 Markdown 表格及旧正文中的制表符表格，宽表格可横向滚动。
- 保存可读取的内联 SVG 图表快照，包括曲线、坐标和文字；读取完整回答，避免遗漏正文之外的图表。
- 浏览器采集扩展与登录读取使用相同提取规则，保留加粗文字。
- 图表标签可检索和用于摘要，绘图坐标不混入检索及模型上下文。
- 图表内容经固定 SVG 元素、属性白名单处理，不加载外部资源或执行原页面脚本。

已丢失的图形需要重新登录读取原会话。快照保留静态图形，原图交互和悬浮提示请打开原链接；Canvas、iframe 和跨域嵌入内容暂不支持转存图形。

安装版可在「模型与设置 → 版本与升级」检查更新。升级保留已有知识库。使用浏览器扩展的用户需重新加载新版扩展。
