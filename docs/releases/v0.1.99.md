# Stellar Secretary v0.1.99

Library conversations now survive page reloads and closed browser windows, with editable conditions and more complete source reading.

- **Recoverable questions:** answers are saved by the background service. Reopening a page restores completed answers or reconnects to an active request without submitting it again. Application restarts leave interrupted requests retryable. Stale browser snapshots cannot overwrite a newer answer.
- **Stop and retry:** stop an individual CLI/API request, retry a failed answer, and retain a previous completed answer if a recheck fails. Unverified streamed output is not cached as a final answer.
- **Better context:** retain the last sourced topic across general conversation, bind explicit conditions to their sources, and edit or remove individual conditions without changing original messages. Removed conditions are also excluded from recent model history.
- **Faster follow-ups:** short, unambiguous schedule follow-ups can reuse cited evidence without another planning call. Prepared evidence images are reused within bounded memory/time limits, invalidated by source/file changes, and still supplied to the answering model. Check again bypasses reuse.
- **Read more when needed:** long sources receive bounded relevant-section and neighboring-chunk reading. Anchored PDF evidence can include up to two adjacent text pages from the original, with page references retained. This does not rewrite saved reading ranges or automatically run OCR.
- **Consistent references and lists:** historical citations flag updated or trashed sources. Empty history-topic catalogs can fall back to shared subject keywords when combined synonyms would otherwise miss records, with the actual search scope shown.
- **Clearer setup:** local detection and a compact bilingual guide explain CLI/API readiness, keyword search without model downloads, and optional semantic-search configuration.
- **Background reliability:** added checks for summary completion without a GUI, persisted results, source deletion during questions, company-model confirmation, and reconnecting after suspended-page clock gaps.

Validation includes the full unit suite, browser conversation/citation/language regressions, Windows and Linux source/native-window checks, a synthetic live Codex question matrix, and frozen-package background-question checks. Simulated suspend gaps were verified; physical sleep/wake remains a manual acceptance check. Test records and model fixtures are synthetic, and private library contents and screenshots are not shipped.
