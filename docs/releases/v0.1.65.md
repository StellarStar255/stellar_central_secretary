# Stellar Secretary v0.1.65

Fix Windows automatic installation and desktop restart after checking for updates.

- Replace detached PowerShell startup with a hidden console. The old launch mode could exit without executing the installation script.
- Wait for an explicit installer-helper readiness acknowledgement before closing the app. If the helper cannot start, keep the current app running and show the failure.
- Isolate Windows PowerShell module paths and bundled DLL/Qt paths from the launcher environment. Relaunch the installed app with a fresh PyInstaller environment.
- Explicitly update the current installation directory and preserve desktop mode, the data directory and custom port when restarting.
- Recheck the installer checksum after handoff, keep helper and Inno Setup logs, and surface a previous installation failure after reopening the app.
- Add real Windows helper regressions and an installed-app update transaction to the release pipeline. The transaction checks downloaded checksums, clean exit, file replacement, native desktop restart, Unicode/space-containing paths and every archived item column.

Validation: 247 unit tests on macOS and Windows (platform-dependent skips), JavaScript regressions, and a successful real Windows installed automatic-update transaction. Every release now repeats the Windows installation transaction before publication.

**Existing Windows installations:** if the old updater cannot start the installer, download this version’s Windows setup file from this release and run it once to upgrade in place. Keep the existing installation directory. Local library data is stored outside the installation folder and is preserved. Future updates use the corrected helper.

中文：修复 Windows 检查更新后自动安装失败。旧版后台启动方式可能令 PowerShell 直接退出而不执行脚本；新版确认安装助手就绪后才退出程序，失败时保留程序并显示原因。隔离 PowerShell 模块与打包 DLL/Qt 环境，明确覆盖当前安装目录，重启时保留桌面模式、资料目录和自定义端口。补充交接后的校验、助手启动日志、安装日志与上次失败提示。已在真实 Windows 虚拟机中验证完整下载、安装、桌面重启和资料字段保留，并纳入后续发版检查。

**旧版 Windows 用户：**如果旧版自动更新无法启动安装器，请手动下载本版 Windows 安装包，运行一次并保留原安装目录即可覆盖升级；本机资料保留。之后的更新使用修复后的逻辑。
