# Stellar Secretary v0.1.16

macOS 菜单栏改用与 Dock 一致的知识秘书专属图标。

- 固定使用深色圆角底、橙色星芒标志，处理任务时也保留品牌图形。
- 图标右下角的小圆点表示状态：绿色就绪、橙色处理中、红色异常、灰色启动中。
- 移除菜单栏常驻状态文字，悬停或展开菜单仍可查看具体状态和任务数量。
- Dock 运行标记、任务角标、打开主界面和退出等功能保留。

已验证原生菜单栏与 Dock 的启动、任务状态切换和正常退出，以及签名安装包运行。macOS 安装包经 Apple Developer ID 签名、公证和票据装订，附件提供两平台安装包及 SHA256SUMS.txt。
