# Stellar Secretary v0.1.20

知识库支持空格分隔多个关键词，按「全部包含、顺序不限」匹配资料。例如「科学美国人 6月」与「6月 科学美国人」得到相同结果。

- 关键词可分布在标题、正文、摘要、标签、主题、文件名和来源链接中。
- 忽略英文大小写，支持连续空格、全角空格和换行，继续叠加资料类型与主题筛选。
- 修复宽泛分词匹配导致只包含部分关键词的无关资料也被列出的问题。
- 快速修改搜索词时丢弃过期结果，避免旧请求覆盖当前搜索。

包含此前 PDF 加密读取修复，PDF 默认只用前 5 页生成概览，支持按需生成全文摘要。

macOS 安装包使用 Apple Developer ID 签名，并完成苹果公证和票据装订。
