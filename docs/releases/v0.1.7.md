# Stellar Secretary v0.1.7

- 提供 macOS Apple 芯片 DMG 和 Windows x64 安装程序，不再要求安装 Python。
- 设置中可检查更新、一键下载、校验、安装并重启。自动升级依赖本仓库正式 Release 中的安装包与 SHA256SUMS.txt；macOS 自动替换还要求团队 3QCL9WNFBB 的有效开发者签名。
- 安装版资料独立保存在用户目录，升级与卸载保留知识库和浏览器资料。源码版继续使用项目的 data 目录。
- 在磁盘镜像内运行或应用目录不可写时，打开安装包供手动安装。
- 新增 GitHub Actions 构建、安装版服务冒烟测试、校验和与标签发布流程。

macOS 下载 `Stellar-Secretary-0.1.7-macos-arm64.dmg`，将 Stellar Secretary 拖入「应用程序」。Windows 下载 `Stellar-Secretary-0.1.7-windows-x64-setup.exe`。

仍需另行安装 Google Chrome，以及已登录的 Codex CLI 或 Claude Code。未配置开发者证书和公证凭据的 macOS 构建使用临时签名，首次运行需在系统设置中允许打开；该构建不能作为自动替换的更新目标。Windows 构建未做代码签名。
