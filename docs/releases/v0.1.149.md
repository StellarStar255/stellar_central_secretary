# Stellar Secretary v0.1.149

Windows upgrades from 0.1.148 now wait for temporary WebEngine file locks before replacing browser resources. After a manual reinstall, the app verifies the installed version, interface and library before dismissing an older update warning. The original diagnostic logs remain available.

## 中文

从 0.1.148 升级时，Windows 安装器会等待 WebEngine 文件的临时占用解除，再替换浏览器资源。手动重装后，应用会核对安装版本、界面和知识库，通过检查后自动隐藏旧升级告警，并保留原始诊断日志。
