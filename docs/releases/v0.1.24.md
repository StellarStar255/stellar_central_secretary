# Stellar Secretary v0.1.24

macOS 支持独立桌面窗口和网页模式，切换入口收进「模型与设置 → 使用方式」，主界面不再常驻显示切换按钮。

- 托盘仍提供两种模式的切换，程序记住上次选择。
- 独立窗口关闭后继续在托盘运行，点击 Dock 可以重新打开。
- 桌面与网页共用知识库、设置和本机共享对话；旧浏览器对话在刷新新版网页后迁移。
- 桌面窗口内导航后仍正确识别当前模式，避免切换按钮显示错误。
- Windows 保持网页界面，独立窗口适用于 macOS 安装版。

macOS 安装包使用 Apple Developer ID 签名，并完成苹果公证和票据装订。
