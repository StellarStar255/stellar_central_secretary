# Stellar Secretary v0.1.121

Recover readable PDF content when the regular parser reaches its content-stream safety limit or cannot read the document structure.

- Keep the regular parser's safety limits and automatically fall back to PDFium, reading at most the first five pages and 8,000 characters per page. This applies to upload, reparse and grouped attachments, while preserving the complete original file.
- Show the page range, total page count and any truncation. These parser limits concern PDF instructions and are independent of the model's token budget.
- Mark fallback text and summaries as a partial overview. Do not present that overview as a full-document summary; additional pages can be read or processed with OCR separately.

Validation: 444 Python tests (11 platform-dependent skips), JavaScript conversation regressions and real 51 MB PDF UI checks passed. The new PDF tests exercise an actual PDFium fallback after a simulated parser limit, verify that only five pages are accessed, enforce character bounds, preserve the original bytes, and check upload/reparse/grouped-attachment and summary behavior. The UI checks cover preview, thumbnails, original byte ranges and explicit partial-summary scope. Source trial used the existing knowledge library. Publication additionally requires packaged-program checks, three-platform CI, Mac signing/notarization and remote asset checksum verification.
