# Stellar Secretary v0.1.110

Make browser capture a single action, with reliable archive receipts in the current chat.

- Automatically archive selected text or loaded webpage content. When no readable content is available, or the page is a drawing canvas, bookmark its title and URL instead. Clearly distinguish bookmarks from captured content.
- Save a compact archive card in the chat active when the browser capture was submitted. Preserve receipts across refreshes, concurrent chat saves and request retries; retain unrelated messages when deleting archived material.
- Show connection, capture and save progress, actual service errors, uncertain-save warnings and a direct archive-view link. Verify saved content before reporting success; offer a capture-file download when the desktop is unavailable.
- Recapturing a URL whose old record is in the recycle bin creates a new archive. Keep the discarded record intact and deduplicate later captures against the new active record.
- Improve the iPhone source trial scanner with pairing-code validation, explicit cancellation, retry and camera-permission handling. Keep the scanner open until the pairing request is accepted. Device connectivity remains a trial and is not an App Store or TestFlight release.

Validation: full Python unit suite, JavaScript chat and browser-popup regressions, isolated extension-installation UI checks, native Swift pairing-code tests and existing iPhone simulator checks. Three-platform release builds and a signed, notarized Mac package are required before publication. Actual iPhone-to-Mac connectivity has not yet been confirmed.
