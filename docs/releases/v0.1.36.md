# Stellar Secretary v0.1.36

改进本地代理网页打开与中断处理，避免直接将导航异常作为读取结果。

- 打开网页时等到导航提交，再由用户确认并检查正文加载，不依赖可能被动态页面替代的初次 DOMContentLoaded 事件。
- 临时空响应或未提交的中断导航重试一次；已提交的目标页面可继续进入确认流程。
- 区分持续 HTTP 204/205 空响应、下载、HTTP 错误和连接拒绝，显示具体处理提示，不保存这些错误页面。
- 本地查看器跳转至同源索引或会话路径后，确认读取当前页面；继续限制原始主机、协议和端口，保留收藏的原链接。
- 真实启动临时网页源站及独立回环转发端口，复现 HTTP 204 引起的 ERR_ABORTED，并验证临时恢复、动态正文、HTTP/脚本跳转、下载及服务错误。测试不访问用户实际服务或调用模型。

English: Improve navigation handling for local proxy viewers. Retry interrupted empty navigation once, distinguish HTTP empty/error/download responses, and allow explicitly confirmed same-origin local viewer redirects while retaining the original saved link.

ERR_ABORTED 的原因不唯一；模拟页面复现不代表已经确定用户服务的实际响应。macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
