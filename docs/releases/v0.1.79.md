# Stellar Secretary v0.1.79

View HEIC/HEIF photos and summarize their image contents while preserving the originals.

- Decode HEIC/HEIF locally for attachment thumbnails and the in-app image viewer, including zoom and gallery browsing. Compatible JPEG previews are generated locally; original downloads remain byte-for-byte intact.
- Send compatible images to an image-capable model for visual summarization and searchable image descriptions. Existing HEIC attachments and older standalone HEIC imports work without re-uploading; use **Summarize again** to replace a summary that previously could not read the image. An API model must have image input enabled.
- Recognize HEIC/HEIF when choosing, pasting or appending attachments. Keep image input bounds and original-file preservation, and include the native decoder and third-party notices in the packaged applications.

Validation: 307 Python tests (10 platform-dependent skips), chat UI regression, real-browser HEIC regression for legacy and new attachments, mock-model verification of actual JPEG input, preserved original downloads, corrupt/oversized-image handling, and a frozen Mac smoke check including native HEIC decoding. No user files or live model calls were used for these tests.

中文：本版支持 HEIC/HEIF 照片的本地缩略图、应用内预览、缩放及视觉总结。原件完整保留，预览和模型分析使用本地生成的兼容 JPEG。已入库 HEIC 附件及旧版单独导入的 HEIC 无需重新上传；更新后点击“重新总结”即可重新读取图片内容。需使用支持图片输入的模型，API 模式需启用图片输入。安装包包含原生解码组件与第三方声明。
