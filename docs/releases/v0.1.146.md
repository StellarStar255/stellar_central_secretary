# Stellar Secretary v0.1.146

- On Windows, if the saved library is missing after a reinstall or restart, the recovery dialog lets you retry the original location, open an existing library, or create a permanent library in an empty folder. Existing files are preserved. The interactive tutorial covers creating a new library.
- The chat composer now shows a clear Archive only checkbox in both appearance modes. The send-mode menu fits the selected label and the controls wrap on narrow windows.

## 中文

- Windows 重装或重启后，如果找不到原知识库，可重试原目录、选择已有知识库，或在空文件夹中新建知识库。新库会成为以后启动时使用的知识库，原有文件会保留。交互教程增加了新建知识库的操作示例。
- 浅色和深色界面都能清楚显示聊天输入框的「仅归档」复选框。发送方式下拉菜单随所选文字调整宽度，窄窗口下控件可以换行。
