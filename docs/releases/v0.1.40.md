# Stellar Secretary v0.1.40

Paste images, text and files together and save them as one archive.

- Paste PNG/JPEG/GIF/WebP images into the composer; clipboard text is retained. Add files before sending to keep their context together.
- Select **Ask about these materials** for a question scoped to the submitted group. Ordinary annotations respect the automatic-summary setting.
- View original images, preview PDF attachments and download individual originals. Grouped originals, summaries and AI image descriptions participate in search and backups; deleting the archive removes its attachments and referencing chat messages.
- Image analysis uses the selected local Codex / Claude CLI and its online model account. Relevant text and resized images are sent to that provider. Image descriptions are labeled as AI generated; private quick notes remain excluded.
- Limits: 20 attachments, 8 images and 50 MB per submission. Long texts use bounded excerpts, grouped PDFs use the first five pages, and originals remain intact.
- Corrected conversation object handling after archive deletion so subsequent messages remain in the active conversation.

中文：支持直接粘贴图片，与文字、文件作为同一次提交归档；可只针对本组资料提问，保留原件、预览、检索、备份及整组删除。图片解读与原文分开标注，需核对原图。

Validated with synthetic grouped materials, browser interaction, backup restoration, scoped model input, deletion cleanup and frozen-app checks. The macOS package is signed with Apple Developer ID and notarized.
