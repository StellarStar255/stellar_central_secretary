# Stellar Secretary v0.1.60

Open recorded local paths and quick-note images directly from archived material.

- Double-click a local path in the source text to open its folder in the system file manager. File paths reveal the file in its folder. Keyboard users can focus the path and press Enter.
- Recognizes absolute local paths, Chinese names, spaces, quoted paths and home-directory paths. Existing records work without saving them again. Missing paths and paths belonging to another computer show an error.
- Quick-note image thumbnails now open in the system's default image viewer instead of opening a browser tab. Images retain their original bytes and use a verified image extension when opened.
- Open actions validate that the path or image belongs to the selected archive. Recorded files are located without executing them, and archived text, summaries and quick notes are preserved.

Validation: unit tests, real-browser double-click and keyboard checks, missing-path and ownership checks, quick-note autosave and image-opening checks, and packaged application smoke tests. Windows and Linux run the new browser checks before publication.
