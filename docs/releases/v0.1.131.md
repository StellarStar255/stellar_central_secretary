# Stellar Secretary v0.1.131

- The desktop model proxy menu offers local HTTP / Mixed port examples for 7897, 10808, 1080, and 8080.
- The iPhone companion supports Simplified Chinese and English. Choose a language on the welcome screen or under **Connection → Display Language**. The interface updates immediately and remembers the choice after relaunch.
- The READMEs now show the paired iPhone app in dark mode as it saves a note, searches the sample library, and opens a cited record.

This release includes desktop installers and the updated iPhone companion source. The language switch is available in iPhone development builds.

- iPhone 配套版支持简体中文和英文。可在欢迎页或「连接 → 显示语言」直接切换，立即生效，重新打开 App 后会记住选择。
