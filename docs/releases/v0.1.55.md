# Stellar Secretary v0.1.55

Guided proxy setup and HTTP/SOCKS5 routes for the dedicated capture browser.

- Replace the proxy URL box with a computer choice and a port-number field. Examples fill in common local ports; a three-step guide explains where to find the port in the proxy app.
- Dedicated Chrome can follow the system, reuse the model connection, connect directly, or use a separate HTTP/SOCKS5 proxy. SOCKS5 examples show the type and port explicitly. Username/password proxy URLs are not supported.
- Save browser routes for ChatGPT conversation capture and general webpage capture. Changing routes requires closing an existing dedicated browser before reuse; sign-in data is retained. Daily browser windows and browser-extension settings stay under their own browser's control.
- Check a proxy port without calling a model. Model connection tests first check the selected route, then show elapsed time while waiting for the model. A busy test queue reports an error after five seconds instead of waiting indefinitely. Local model APIs continue to bypass external proxies.
- Prevent delayed status responses from overwriting newly saved proxy settings.
- Update checks now show immediate progress and a completion message. Builds that cannot automatically install an available update show an installer download link.

Validation: 187 Python tests (185 passed, 2 conditional skips on macOS), JavaScript UI regressions, real Chrome HTTP/SOCKS5 navigation through isolated proxies, and real Chrome settings save/reload in Chinese and English. Model/API tests use synthetic local services; a separate existing-app Codex connection through local port 7897 succeeded in about 12 seconds. Port examples are not guaranteed to match another computer's proxy configuration.
