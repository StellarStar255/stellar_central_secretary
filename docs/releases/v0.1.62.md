# Stellar Secretary v0.1.62

View images inside the app and rename items directly from the library preview.

- Image thumbnails in quick notes, chat messages, archived attachments and supplemental materials now open in a built-in image viewer. No browser tab or external app opens when viewing a thumbnail.
- Zoom with the toolbar or mouse wheel, drag to pan, double-click to zoom/reset, switch images with the arrow buttons or arrow keys, and press Esc to return to the underlying screen. Explicit default-app editing actions remain available for attachments.
- Images in the message composer and supplemental-material drafts can also be previewed before saving or sending.
- Double-click the title in the library preview to edit it in place. Enter saves, Esc cancels; keyboard users can focus the title and press Enter or F2. Saved titles update the results list and persist after restart.
- Background refresh preserves an active title draft. Renaming preserves the source, summary and attachments and does not call a model.

Validation: unit and JavaScript regressions; real-browser image viewing, zoom, pan, gallery navigation, draft previews and external-editor fallback; library title save/cancel, background refresh and reload persistence; frozen-application asset and archive checks.
