# Stellar Secretary v0.1.28

新增通用网页浏览器采集，支持飞书项目等需要登录或动态加载的网页。

- 直接抓取没有正文时打开专用 Chrome，也可点击「浏览器读取网页」。
- 手动登录并展开目标工作项、评论后，点击「页面已打开，开始读取」。保留原链接的查询参数及片段。
- 保存已加载正文及 HTML 表格，摘要明确标注采集范围；不自动遍历分页或读取未加载内容。
- 排除隐藏内容、表单值及未提交的编辑草稿；登录页及无权限提示不会作为正文保存。
- 成功后按设置仅关闭本次任务新开的标签页；失败保留页面及已有资料。
- 兼容本地代理的 Fake-IP DNS 模式，经连接验证后使用现有本地代理打开任务浏览器；无需修改系统网络设置。
- 新增中英文按钮、等待状态和提示，保留 ChatGPT 专用读取流程。

English: Authenticated and dynamic webpages now have a **Read webpage in browser** action. Sign in, expand the target content and click **Page is ready, start reading**. Loaded text and HTML tables are archived with an explicit scope note. Existing tabs and stored material are preserved. Canvas, embedded or restricted content may require the extension or manual text.

验证：80 项单元测试（2 项可选测试跳过）、聊天界面回归、真实 Chrome 网页采集及标签页生命周期检查、中英文与教程回归。macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
