# Stellar Secretary v0.1.138

- On the first launch of a fresh installation, the main window opens an interactive tutorial with six exercises. You can skip it or reopen it from **Models & settings**. Existing libraries do not trigger the tutorial during an upgrade. The exercises use sample data and make no model calls.
- The English README now shows the iPhone companion in English. The Chinese README retains its Chinese demonstration.
