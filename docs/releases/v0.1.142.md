# Stellar Secretary v0.1.142

- The optional Memory MCP interface lets Codex CLI, Claude Code, Gemini CLI, and other MCP clients search and read archived records on the same computer. Start from source with `--memory-mcp` to enable read-only access.
- Both READMEs include setup commands and an example query. The desktop startup tutorial adds an optional MCP section with a link to the setup instructions in the tutorial's language.
