# Stellar Secretary v0.1.88

Fix automatic-mode questions and follow-ups taking different paths, and improve evidence checks for saved timetables and images.

- **One conversation flow:** auto-detected text questions now use the same context-aware retrieval as Library chat. Follow-ups such as “look at the timetable again” and “continue” remain questions instead of being archived as new notes. Explicit archive choices and command archiving retain priority.
- **Relevant evidence:** planned keyword searches take priority; the entire question is a fallback so generic words do not fill the result list. Follow-ups can reload the previously cited document’s context. Responses display only sources actually cited, including when reopening older conversations; invalid source numbers produce a clear retry error.
- **Recheck saved images:** related retrieved images are passed to an image-capable model as bounded compatible previews, without rewriting originals or summaries. Unsupported, unavailable and limited image input is disclosed to the answering model. Up to four images and a 6 MB image budget keep each request bounded.
- **Date-aware answers:** explicit local date, weekday, time and UTC offset help interpret “today” and “this week.” Timetable answers distinguish visible date ranges, week numbers, out-of-week labels and partial views. An empty cell in an older week cannot establish today’s availability without a documented recurrence rule.
- **Concurrent quick-note attachments:** reread the current revision and retry up to three attempts when note autosave advances the item version during an additive attachment append. Other errors retain the visible retry queue; original text and existing attachments are preserved.
- **Readable answers:** cited assistant answers render safe Markdown, including bold text, instead of showing formatting markers literally.

Validation: 336 unit tests passed with 10 platform-specific/opt-in skips; chat UI regression and real-browser automatic-mode timetable/follow-up regression passed. Existing library chat, semantic search/fallback and Chinese/English checks passed. Real-browser command archiving, summary performance, quick-note retry, forced note-autosave/attachment revision-conflict, company-data confirmation, video, PDF, restore, backup and upload-resume checks passed. Company-data checks separately verify question-only query planning and block protected retrieved evidence before confirmation. An additional check with the configured real model re-read a saved timetable image for both the initial question and follow-up, using an isolated copy and preserving the original archive. No private images or test data are included in the release.

中文：本版修复自动识别模式的问题和追问走不同路径的错误。「看下课程表再告诉我」「继续」现在沿用知识库对话，不再被误归档。明确选择归档、仅归档及普通命令的处理保留。

检索优先使用模型提取的主题词，完整问题仅作回退，减少泛词造成的无关结果；追问可重新载入已引用资料上下文。只展示回答实际引用的来源，旧对话也会过滤未引用卡片。相关图片会在数量和体积限制内重新提供给支持图片的模型核对，不改写原件和旧摘要。

回答显式接收本机日期、星期和时区，核对课表日期范围、周次、“非本周”标记及截图可见范围，不会把旧周的空白直接推断为今天无课。带来源的回答正常显示加粗等安全 Markdown 格式。

已通过 336 项单元测试（10 项平台或手动启用测试跳过）、自动模式原问题/追问浏览器回归及现有知识库、语义检索、中英文检查；另使用当前真实模型在隔离副本上重新核对原图，原资料保持不变。发布不包含个人截图、原图或测试资料。

另修复速记自动保存与附件追加同时发生时的版本冲突：仅针对已识别的追加版本冲突重新读取并最多尝试三次，其他失败仍保留文件队列供重试。通过真实浏览器强制冲突检查，确认不丢失文字、不重复保存附件，并保持普通归档及「仅归档」不调用模型。
