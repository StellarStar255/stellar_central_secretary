# Stellar Secretary v0.1.14

macOS 安装版新增原生菜单栏和 Dock 运行状态，启动后能直接确认知识秘书是否正在运行。

- 菜单栏显示品牌图标及启动中、就绪、处理中、升级中或异常状态；展开菜单查看会话读取、资料整理和问答数量。
- 菜单支持打开主界面、打开资料文件夹、查看运行日志和退出。关闭网页后图标仍保留，退出会停止本机服务并移除菜单栏图标。
- Dock 使用正式应用图标，运行时保留运行标记，处理任务时显示读取、整理、问答或升级角标；点击 Dock 图标重新打开主界面。
- 有任务或升级进行中时提示先完成或停止任务，避免误退出。正常服务关闭及一键升级也会退出原生事件循环。
- 替换 macOS 和 Windows 安装包的默认程序图标。原生菜单栏和 Dock 状态仅用于 macOS；Windows 的网页使用方式保持兼容。

验证包括启动、就绪、整理、读取、恢复就绪、打开主界面和退出的真实 Cocoa 菜单栏/Dock 检查，以及安装包归档、导入、正常关闭检查。

macOS 安装包使用 Developer ID Application: Qiliang Huang (3QCL9WNFBB) 签名，通过苹果公证和票据装订。Windows 安装包未做代码签名，附件提供 SHA256SUMS.txt。安装版可从「模型与设置 → 版本与升级」一键更新。
