# Stellar Secretary v0.1.51

Recover automatically when PDF summarization reaches a model timeout.

- A timed-out summary request is divided into smaller parts and retried once per job. Previously completed segment notes are retained. Recovery has a separate four-minute budget, and each recovery call is limited to 90 seconds.
- Codex text summaries use low reasoning effort. Authentication errors, invalid responses and stopped tasks are not automatically retried.
- API response timeouts are distinguished from connection failures. Timed-out CLI workers are terminated and their pipes closed; stopped jobs cannot save late results.
- Original files, extracted text and search indexes remain saved. Automatic PDF summaries still cover the first five pages; full-document summaries remain available on request.

Validation: 159 Python tests (157 passed, 2 conditional skips) on macOS; process cleanup checked with resource warnings treated as errors. Using the supplied 23-page `2212.10560v2.pdf`, the first-five-page overview completed in 21.5 seconds and the full summary in 174.5 seconds. Injecting one initial timeout followed by real Codex recovery calls completed in 65.9 seconds. The original intermittent 240-second timeout was not reproduced in these live runs; the recovery path was verified with fault injection. Timings depend on the model and network.

Installers: Windows x64 setup EXE, Apple Silicon macOS DMG (Developer ID signed and notarized), and Linux x64 Debian / portable packages. Linux requires glibc 2.35+ and uses the browser interface. Existing data is preserved across updates.
