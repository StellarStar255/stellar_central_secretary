# Stellar Secretary v0.1.78

Image previews leave room around the viewer so you can return to your work easily.

- Keep visible space around enlarged image previews, including on smaller screens. Click outside the preview to dismiss it and return to the underlying details; the close button and Escape remain available. Zooming, panning and gallery navigation continue to work.
- Add the native macOS Window → Close Window menu item with Command-W. It closes the current desktop window while the background service continues running; reopen the window from the Dock or menu bar.

Validation: browser regression covers preview margins, outside-click dismissal, Escape, zoom, pan and gallery navigation. Native macOS regression verifies Command-W through the menu and responder chain, background service continuity and window reopening.
