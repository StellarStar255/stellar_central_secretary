# Stellar Secretary v0.1.75

Fix Windows updates that abort while replacing Chromium resource files.

- The installer now checks all installed file types for use, including `v8_context_snapshot.bin`, `.pak` and `.dat` resources. Previously the default executable/library filter could miss a locked resource and abort partway through installation with Windows sharing error 32 and installer exit code 5.
- After the main application exits, the update worker waits for desktop-host shutdown, handles only orphaned WebEngine processes from the target installation and checks resource replacement access before starting installation. Another active application instance blocks installation before files are changed. Windows short/long path aliases are normalized when identifying process ownership; retained process handles avoid PID-reuse mistakes.
- The installer also handles orphaned WebEngine processes before file replacement, covering updates initiated by older update assistants. Other installations and unrelated same-named browser processes are excluded. Installation failures report the actual exit code and installer-log location.
- Real Windows regressions reproduce the locked V8 snapshot, confirm unrelated processes survive, exercise active-instance protection and normal desktop shutdown, and verify direct installer recovery for the legacy handoff path. Download/checksum verification, in-place install, automatic restart, failed-version rollback, Unicode paths and every archived-item column are checked.

中文：本版修复 Windows 自动更新时 V8 快照等浏览器资源被占用、导致安装退出码 5 的问题。安装器扩展文件占用检查并兼容旧版更新助手；更新前等待桌面宿主退出，只处理当前安装目录的残留 WebEngine 进程，仍活跃的另一实例会阻止安装。已在真实 Windows 环境复现并通过文件锁、安装、自动重启、回退和资料保留验证。
