# Stellar Secretary v0.1.132

- The iPhone companion now uses its in-app language setting for navigation titles. Quick Capture, Connection, Library, record details, and other screens display the selected language even if the iPhone uses a different system language.

This release includes desktop installers and updated iPhone companion source. The fix is available in iPhone development builds.

## 中文

- iPhone 配套版的导航标题现在跟随 App 内的显示语言。即使 iPhone 系统语言不同，随手归档、连接、知识库和资料详情等页面的标题也会按 App 内所选语言显示。

本次发布提供桌面安装包和更新后的 iPhone 配套源码。标题修复可在 iPhone 开发版中使用。
