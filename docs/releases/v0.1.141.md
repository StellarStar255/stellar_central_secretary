# Stellar Secretary v0.1.141

- The library search box shows up to five recent searches. Type to find older entries, or select one to fill the search box and search again. You can remove one entry or clear the history.
- **Clear filters** is available both beside matching results and on the empty results screen. It clears the library filters and reruns the search with your original keywords and sort order.

## 中文

- 知识库搜索框最多显示 5 条近期搜索。输入几个字可查找更早的记录，选中即可填入并重新搜索。历史支持单条删除和全部清空。
- 有结果时可以在结果数旁清除筛选，无结果时可以在空结果页清除。清除后会保留关键词和排序，并立即重新搜索。
