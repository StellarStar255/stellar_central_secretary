# Stellar Secretary v0.1.109

Keep Windows model calls in the background and add an optional phone-connection trial.

- Fix console windows appearing when asking questions or organizing material on Windows. CLI model calls, model API workers and capture workers now share a no-console startup policy while retaining piped output, error handling, timeouts and cancellation.
- Validate actual Windows process creation for both direct executables and `.cmd` wrappers, including Unicode input/output and absence of an allocated console. Interactive browser login remains available through the existing browser workflow.
- Add an opt-in **Phone connection** setting for the native iPhone companion source trial: expiring QR invitation, matching approval digits on the desktop, pinned TLS, paired-device revocation and Bonjour discovery. The desktop listener is off by default.
- The iPhone companion source supports note/link/image/file capture, library search, cited text, questions and a persistent offline outbox. Links are initially bookmarked; the desktop can complete webpage reading. Keep the computer awake on the same reachable LAN.

Validation: full unit suite, JavaScript chat regressions, successful Windows/Linux source validation including native window lifecycle, isolated desktop pairing controls, native iPhone simulator pairing/capture/search/outbox/reconnect checks, iPhone device-architecture build and frozen Mac companion dependency checks.

The iPhone app is a source trial, not an App Store or TestFlight release. Physical iPhone installation, camera scanning and actual Wi-Fi permissions still need device testing. See [installation instructions](https://github.com/StellarStar255/stellar_central_secretary/blob/v0.1.109/ios/README.md).
