# Stellar Secretary v0.1.26

支持简体中文与 English，可在「模型与设置 → 显示语言」即时切换并保存选择。

- 网页、独立桌面窗口和 macOS 原生菜单共用显示语言偏好。
- 切换时保留正在输入的草稿、已选附件和未保存的其他设置；原始标题、正文与已有摘要保持不变。
- 互动教程与离线 HTML 支持中英文，并可在教程页单独切换，保留练习进度和自定义示例标题。
- 提供中英文两版操作动图与英文 README。
- 使用统一翻译目录，翻译只应用于界面源文案，不对用户内容做全页替换。

English: Choose **Models & settings → Display language → English**. The choice is shared between browser and desktop modes and survives restart. Existing material stays as saved. The interactive/offline tutorial, native macOS menus and demo GIFs are available in both languages.

macOS 安装包使用 Apple Developer ID 签名，并完成苹果公证和票据装订。
