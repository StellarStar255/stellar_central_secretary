# Stellar Secretary v0.1.166

The iPhone companion can capture multiple views of an item in one session. Tap a thumbnail to review the photo, remove unwanted shots and adjust the order before adding them to the draft. Automatic photo naming is enabled by default and can be turned off before upload.

The companion and desktop gateway support binary attachment uploads. When connected over Bluetooth, the phone looks for a faster local connection while you select photos and retries Wi-Fi routes that become available during upload preparation. Adding a photo to an existing record shows upload progress.

Archived plans can resolve relative dates such as “next Saturday” using the original note date.

## 中文

iPhone 可以连续拍摄同一物品的多个角度，点缩略图查看大图、删除照片，调整顺序后一起加入草稿。照片自动命名默认开启，上传前可以关闭。

手机和电脑支持以二进制传输附件。通过蓝牙连接时，手机会在选图期间寻找更快的本地连接，并在准备上传时重试刚恢复的 Wi-Fi 线路。向已有归档添加照片时可以查看上传进度。

归档计划时，秘书可以依据原笔记日期，将“下周六”等相对时间换算为具体日期。
