# Stellar Secretary v0.1.39

新增归档右键删除菜单，并清理引用该记录的对话副本。

- 在最近归档、知识库条目、归档卡片或来源卡片上右键，选择「删除归档…」，核对标题后确认；默认焦点为取消。
- 删除记录、原文件、速记附件、正文历史副本、程序生成的打开副本和搜索索引，保留其他归档。
- 清理引用该记录的对话消息及关联请求，更新对话标题，防止旧窗口同步恢复已删摘要；浏览器中的关联速记草稿也会清理。
- 处理中或已更新的记录会拒绝过期删除；文件移动失败时回退，清理未完成时明确提示并在重启后重试。
- 使用虚构记录验证取消、处理中保护、文件及索引清理、旧缓存、最后一条消息、关联对话和无关记录保留；安装验证不会删除实际资料。

English: Right-click an archive and confirm **Delete archive…** to remove its record, originals, notes, capture-history copies, search entries and referencing chat messages. Other archives remain. Identifier-only deletion markers prevent stale chat sync from restoring removed messages.

删除无法撤销。已导出的备份、原网页及外部已打开窗口不受影响；这不是对外部副本或磁盘的安全擦除。macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
