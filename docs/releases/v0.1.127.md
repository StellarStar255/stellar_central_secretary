# Stellar Secretary v0.1.127

- Re-archive a file, link, or note when its earlier entry is in the recycle bin. The earlier entry can still be restored. Existing active entries continue to be deduplicated.
- On Windows, upgrades keep the existing installation, library, and backup paths. The updater relaunches with the absolute path of the current library.
- A new Windows library and its default backups use a writable non-system fixed drive when one is available. Existing libraries retain their location.

## 中文

- 旧档在回收站时，可以重新提交文件、链接或笔记并建立新档。旧档仍可恢复，知识库里已有的有效归档仍会去重。
- Windows 升级沿用已有的安装目录、资料库和备份路径。升级重启时使用当前资料库的绝对路径。
- Windows 新建资料库时，优先把资料和默认备份存到可写的非系统固定磁盘。已有资料库沿用当前目录。
