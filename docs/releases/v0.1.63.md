# Stellar Secretary v0.1.63

Find original and added attachments together, and open them directly from the library preview.

- A single **All attachments** section at the top of item details combines original files and every supplemental batch. Cards retain their original/added source label; batch history and source text remain available below.
- The library's right-hand preview now shows the same attachments before the summary. Open an image in the built-in full-resolution viewer, open a PDF from its first-page thumbnail, or open another supported file in its default app.
- Image and PDF thumbnails are generated locally, without model calls or uploads. Other file types, damaged PDFs and password-protected PDFs use a file-type card when a thumbnail cannot be generated.
- The image gallery spans original and added images. Downloads, external editing, folder reveal and save-back remain in **More actions**. Source files, summaries and quick notes are preserved.
- The release workflow is now documented as the reusable `stellar-release` skill, with a stable helper for signed builds, CI checks, checksum verification, publication and local updates.

Validation: unit and JavaScript regressions; synthetic browser checks for unified attachments, cross-batch full-resolution viewing, PDF quick-open, edit/save-back and library-title editing; frozen-app PDFium thumbnail, license and asset checks.
