# Stellar Secretary v0.1.157

Library search now suggests up to five recent queries and matching archive titles as you type. Exact matches rank first. Double-click the search field to select the entire query, or use the arrow keys and Enter to choose a suggestion.

Suggestions wait for Chinese input composition to finish and respect the current filters. Clearing recent searches also updates other library tabs in the same browser.

## 中文

知识库搜索现在会在输入时推荐最多五条历史词和资料标题，完全匹配优先。双击可选中整条搜索词，方向键和回车可直接选用建议。

中文选词结束后再搜索，切换筛选会及时清理过期的标题建议。在一个标签页清空历史，同一浏览器的其他知识库标签页也会同步。
