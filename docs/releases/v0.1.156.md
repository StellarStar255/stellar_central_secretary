# Stellar Secretary v0.1.156

When you resend an unchanged link that is already in your library, desktop chat now says so and shows the existing archive card. The notice stays visible after the conversation refreshes, including when the item already has a summary.

## 中文

再次发送已归档的相同链接时，桌面聊天会提示这份资料已在知识库中，可点击卡片查看原归档。已有摘要的资料也会显示重复提示，刷新后仍可看到。
