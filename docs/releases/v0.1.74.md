# Stellar Secretary v0.1.74

Read PDFs immediately, track actual summary coverage, search larger libraries and verify maintenance actions.

- PDF viewing displays original pages immediately without automatically extracting text. Explicit text extraction and local OCR run as bounded background jobs with per-page progress, cancellation and continued work after closing the viewer. OCR releases the PDF rendering lock so pages remain browsable; cancelled jobs do not commit partial text. Existing limits remain 1–10 pages per request and 200 retained pages per item.
- Summary coverage distinguishes extracted pages, pages actually submitted for successful summaries and pages still awaiting summarization. Older summaries have unknown coverage until regenerated. Summarize new pages appends a scoped supplemental summary while preserving the earlier summary; changed page text invalidates its prior coverage.
- Library filtering and pagination now run in SQLite. A trigram index accelerates substring queries; one/two-character terms retain SQL substring matching. Dashboard refreshes fetch recent records, active tasks and current-conversation references instead of the full library. A 10,000-record synthetic regression covers paging, search and dashboard bounds. Standard-SQL dirty markers preserve write compatibility when rolling back to older application versions.
- Storage settings show originals, backups, deleted-attachment recovery copies, upload staging and other local usage. Cleanup requires an explicit preview, individual selection and confirmation. Previews expire after ten minutes and changed files require a new preview. Originals, databases and working edit copies are excluded. The newest and most recently verified backup in each folder remain protected; removing selected recovery copies or older backups is permanent.
- New snapshots include per-file SHA256 manifests and verify the database, original-file hashes, attachment references and note-image references before reporting success or pruning older backups. Backups can also be verified from settings without replacing the live library. Older snapshots are labeled as lacking a per-file manifest. An inconsistent current state is preserved and labeled before recovery, without blocking restoration of a verified good snapshot.
