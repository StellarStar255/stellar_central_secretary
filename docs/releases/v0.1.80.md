# Stellar Secretary v0.1.80

Command-W closes the current layer before closing the macOS desktop window.

- Close the topmost image viewer, detail dialog or other dialog first. Repeated presses work back through the open layers; the main window closes only when no dialog remains. The background service continues running.
- Follow actual dialog opening order, including dialogs reopened in a different order. Use existing cancellation rules so draft saving, video cleanup and busy-operation guards remain effective.

Validation: native macOS Command-W regression covers image viewer → details → library → main window and reordered dialog openings. Browser regression covers title-draft saving and cancellation guards. Chat UI regression passed.
