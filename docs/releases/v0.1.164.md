# Stellar Secretary v0.1.164

Ask for a birthday by name in Auto-detect mode. When archived notes agree on the date, Secretary answers directly from the original note and shows its source card. This works in a new conversation and after a follow-up. Equivalent Chinese date spellings can match while the answer preserves the cited wording.

Conflicting dates, relevant conversation corrections, and questions about calendar conversion continue through library chat. Choose **Check again** to request a fresh review.

Completed answers now appear as soon as the background job reports completion. In a new chat, an explicit keyword list such as **List all records containing "SQLite"** runs locally. A definition question with a named term found in the library can skip the model call for search planning.

## 中文

在「自动识别」模式下输入「小林妈妈生日」，如果归档原文给出了明确且一致的日期，秘书会直接显示生日和来源卡片。新对话和追问都可使用。中文数字与阿拉伯数字等价时也能匹配，回答保留引用资料中的日期写法。

遇到日期冲突、相关对话更正，或需要农历换算时，秘书会结合资料继续核对。点击「重新核对」可以主动发起一次完整问答。

后台问答完成后会立即通知界面显示结果。在新对话中输入「列出所有包含“SQLite”的资料」会直接生成可翻页的本地清单。询问术语定义时，如果库中能找到原词，可以省去一次检索规划的模型调用。
