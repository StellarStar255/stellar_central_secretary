# Stellar Secretary v0.1.128

- Windows in-app updates wait for the old program to exit cleanly before replacing files, and verify that the new interface has opened before reporting success. The installer also reopens the existing app after a direct silent upgrade.
- Save quick notes, pasted images, and other attachments while a summary is running. The active summary and the new attachments are saved independently.

## 中文

- Windows 应用内升级等待旧程序正常退出，安装后确认新版界面已打开，再报告成功。直接静默运行安装包升级时，也会重新打开原应用。
- 资料整理期间可以继续保存速记、粘贴图片和追加文件。正在生成的摘要与新追加的内容分别保存。
