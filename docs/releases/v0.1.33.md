# Stellar Secretary v0.1.33

修复浏览器已经打开、程序却提示无法建立本地连接的问题。

- Chrome 重启后连接标识会变化。旧版只认原标识，随后尝试另开连接，又被同一资料目录中的 Chrome 接管，最终超时。
- 读取前核对专用资料目录、浏览器进程与本机端口，自动找回重启后的连接并更新记录；也支持连接记录缺失的恢复。
- 仅恢复本程序对应专用目录的连接，不接管日常浏览器，不读取或迁移 Cookie、密码。
- 启动等待期间重新检查已运行实例，避免不断尝试新开浏览器。
- 关闭专用浏览器时等待原实例退出，减少快速重开时的竞争。
- 普通网页读取失败时，在资料卡片下方直接显示具体原因。
- 用真实 Chrome 验证重启、连接标识变化、记录缺失、资料目录保留与恢复后的正文读取。

English: Recover capture connections after dedicated Chrome restarts or its connection record is missing. Recovery checks the exact app-owned profile and loopback endpoint, preserves sign-in data and avoids launching another browser instance. Generic webpage errors are now visible beneath the item card.

macOS 安装包使用 Apple Developer ID 签名，完成苹果公证及票据装订。
