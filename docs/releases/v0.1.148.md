# Stellar Secretary v0.1.148

- Local backups track the library that created them. Libraries sharing a backup folder can run daily backups and rotate their own snapshots independently.
- Interrupted backups reclaim temporary space. A failed restore keeps the selected snapshot and the pre-restore copy available for retry or recovery.
- Backup history remembers the five most recently used old folders. Verification, restore and cleanup distinguish copies across folders and recognize aliases for the same folder.
- The desktop app includes a memory MCP helper and setup instructions for connecting AI assistants to your library.

## 中文

- 多个知识库共用备份目录时，各自执行每日备份，并按各自的保留策略清理。复制知识库后可独立备份，通过设置迁移则接续原备份历史。
- 中断的备份可回收临时空间。恢复失败会保留所选备份和操作前的副本，方便重试或回退。
- 备份历史记住最近使用的五个旧目录。验证、恢复和清理都能区分不同目录里的副本，同一目录的多个入口只显示一次。
- 桌面安装包内置记忆库 MCP 工具，并提供连接 AI 助手的配置说明。
