# Stellar Secretary v0.1.25

新增操作动图和可动手练习的交互教程。

- README 动图展示真实程序中的 PDF 归档、组合搜索、标题修改、原件阅读、模式入口与教程入口；使用虚构资料和预置摘要，等待已加速。
- 「模型与设置 → 使用教程」打开六步交互练习，带步骤进度、完成反馈、重置、键盘操作及手机和深色布局。
- 练习内容包括导入 PDF、空格多关键词搜索、修改标题、阅读示例 PDF、模式切换和备份清单。
- 教程不访问知识库接口，不修改程序设置或真实资料，也不调用模型；提供可离线打开的单文件 HTML。
- 提供生成离线教程、验证完整练习和重录动图的脚本，便于随功能更新。

macOS 安装包使用 Apple Developer ID 签名，并完成苹果公证和票据装订。
