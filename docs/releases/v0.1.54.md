# Stellar Secretary v0.1.54

Linux desktop window, tray controls, Dock recovery and installer updates.

- Linux graphical sessions now open a bundled desktop window. **Models & settings → Interface mode** switches between desktop and browser display, preserving the same library, settings and conversation history.
- The Linux tray menu opens the desktop, browser, settings, update panel, data directory and log, and can quit the app. Closing the window minimizes it to the Dock/taskbar; reopening the app restores the existing instance.
- A native application menu remains available when the desktop environment has no tray. GNOME needs AppIndicator support to display tray icons; Dock/taskbar recovery works independently.
- Linux x64 installer builds can check for updates and install from settings. Debian packages request system authorization and verify the checksum, package identity, version and architecture before installation. Cancelling authorization leaves the current app running.
- Portable updates keep the previous program until the replacement starts serving its local API, then remove the backup. A failed startup restores the previous program. Automatic replacement requires system Python 3, a writable program directory and data stored outside that directory.
- Linux packages declare the Qt system dependencies, include a desktop entry and icon, and separate bundled library paths from external browsers, editors and model CLIs.
- `--no-browser` retains the service-only launch option.
