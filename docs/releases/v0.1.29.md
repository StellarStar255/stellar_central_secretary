# Stellar Secretary v0.1.29

修复网页等待确认时堵塞后续 ChatGPT 及其他网页读取的问题，并改进停止与退出。

- 最多四项独立读取任务，一个网页等待登录不再阻塞其他资料；等待队列明确显示「等待读取」。
- 浏览器读取放在独立进程中运行，点击「停止读取」可中断卡在导航或浏览器连接的任务，无需等待网络超时。
- 排队任务可以直接取消，不再进入浏览器；停止后保留已保存正文与摘要，取消任务的迟到结果不会覆盖资料。
- 同一专用浏览器的启动通过进程间锁串行处理，各任务使用自己的标签页，已有窗口和登录资料保留。
- macOS 有任务时退出，可选择「继续运行」或「停止任务并退出」；正在替换应用文件时仍等待安装完成。
- 新增中英文排队、停止及退出提示。原有 ChatGPT 读取范围及通用网页确认流程保留。

English: Waiting for sign-in on one webpage no longer blocks other captures. Browser work runs in isolated processes so Stop can interrupt stuck navigation. Queued jobs cancel without opening a browser. macOS offers **Stop tasks and quit**, preserving saved material and existing browser windows.

macOS 安装包使用 Apple Developer ID 签名并完成苹果公证及票据装订。
