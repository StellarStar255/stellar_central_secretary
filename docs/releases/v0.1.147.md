# Stellar Secretary v0.1.147

- The interactive tutorial uses a quieter layout that puts the current step and practice area first. What's new is available from the top bar.
- Storage cleanup displays an in-app confirmation with the selected count and size, then reports the result. This fixes a missing confirmation on macOS.

## 中文

- 交互教程简化了配色和布局，优先显示当前步骤和练习区。顶部可直接跳到「本版新功能」。
- 存储清理改用应用内确认窗口，显示所选条目数和大小，并在清理后报告结果。修复了 macOS 点击清理时确认窗口不显示的问题。
