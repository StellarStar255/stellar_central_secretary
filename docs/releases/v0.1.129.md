# Stellar Secretary v0.1.129

- Choose separate folders for the knowledge library and its backups, including folders on different drives. The desktop keeps both choices across updates.
- To move an existing library, choose an empty folder and restart. The desktop copies the library and checks the database before switching. The old folder is retained, and backups in the previous location remain available for recovery.
- In the iPhone companion source, open Connection → My Computers → Sort to drag paired computers into your preferred order. The order survives an app restart, and sorting keeps the current computer selected.

This release provides desktop installers and the updated iPhone companion source. The iPhone change is available in development builds.

## 中文

- 知识库和备份可以分别指定目录，也可以放在不同硬盘上。桌面版升级后会沿用已保存的目录。

- iPhone 配套版可在「连接 → 我的电脑 → 排序」拖动已配对电脑。重新打开 App 后会保留顺序，当前所选电脑保持原样。
