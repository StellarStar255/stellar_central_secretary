# Stellar Secretary v0.1.145

- After upgrading, users with an existing library see a dismissible **What's new** notice when a new set of guides is available. The interactive tutorial includes a Windows library recovery exercise and the Memory MCP setup guide.
- Library and backup folders share the same layout. Backup actions wrap as individual buttons on narrow windows.
- Storage cleanup can select or deselect every entry in the current preview. A new scan clears the selection, and cleanup still requires confirmation.

## 中文

- 已有知识库的用户升级后，可以通过「本版新功能」打开最新教程，提示可关闭。新增 Windows 记忆目录恢复练习，并汇总记忆 MCP 接入说明。
- 统一记忆保存目录和备份目录的布局。窄窗口会以完整按钮为单位换行。
- 存储清理支持全选或取消全选当前预览中的条目。重新扫描清空选择，清理前仍需确认。
