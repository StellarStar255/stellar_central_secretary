# Stellar Secretary v0.1.11

修复点击弹窗周围空白区域时弹窗保持打开的问题。

- 资料详情、知识库、模型设置和采集帮助弹窗均支持点击外侧空白关闭。
- 仅在按下与松开都位于弹窗外侧时关闭，避免选中文字、向外拖动或拖动滚动条导致误关闭。
- 保留 Esc 和关闭按钮的原有行为。

已在真实本机页面中使用独立 Chrome 验证全部四种弹窗的外侧点击、内部点击、双向拖动、Esc、关闭按钮及详情滚动条行为。

安装版可从「模型与设置 → 版本与升级」更新。macOS 安装包使用 Developer ID Application: Qiliang Huang (3QCL9WNFBB) 签名，通过苹果公证和票据装订。Windows 安装包未做代码签名，附件提供 SHA256SUMS.txt。
