# Stellar Secretary v0.1.64

Install the bundled browser extension from the app and capture live pages as text snapshots.

- **Models & settings → Install browser extension** now prepares a persistent extension folder outside the app bundle. The guide shows the real folder path and provides copy-path, open-folder and ZIP-download actions. DMG, Windows and Linux installers no longer require a source checkout.
- The extension folder stays at the same location across app updates. Updated extension files can be reloaded from the browser’s extensions page. Browser installation and Developer mode remain manual user actions.
- After confirmation, webpage capture saves the displayed text immediately, including short status pages and constantly changing progress values. The former 80-character minimum and consecutive-stability requirement are removed.
- Captures include a timestamp and identify the result as a text snapshot. Progress values reflect that moment; subsequent changes are not tracked. Empty or loading-only placeholders still wait for readable text. Login, permission and target-address checks remain enforced.
- Moving an item to the recycle bin now cancels its active summary or capture automatically and preserves the latest saved source and summary. A background revision change no longer requires refreshing the page. Late canceled results cannot overwrite a restored item; other items and messages remain unaffected.
- Installer-extension and live-progress browser regressions now run on Windows and Linux before publication.

Validation: 242 unit tests (2 platform-dependent skips), JavaScript regressions, real-browser extension export/copy/download/retry and short progress-page checks, and frozen-worker capture of a confirmed local dynamic page. Frozen-app checks verify bundled extension export and ZIP contents without changing browser settings or user material.

中文：安装版新增浏览器扩展安装入口，可准备固定文件夹、复制路径、打开文件夹或下载 ZIP，无需下载源码或查找 app 内部目录。扩展路径独立于应用升级保留，浏览器内的开发者模式与加载扩展仍由用户手动操作。网页确认读取后立即保存当前显示文字的带时间快照，不再要求至少 80 字或等待进度条、计数器稳定。空白及纯加载占位页仍等待真实文字；登录、权限、地址校验保留。支持很短的进度页，采集数值以当时显示为准，不持续跟踪变化。移入回收站时自动取消该资料的后台任务，不再要求手动停止或刷新；保存最新内容，阻止取消任务的晚到结果覆盖恢复后的资料，其他资料和消息不受影响。
